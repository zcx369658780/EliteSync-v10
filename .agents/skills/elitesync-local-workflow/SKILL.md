# EliteSync Local-first 工程执行

## Authority

当前 Owner 已批准目标和权限、项目 AGENTS 与 CURRENT_WORKFLOW 优先于本技能。本技能不创建产品、数据、运行、设备、网络、供应商、费用或系统权限；不恢复旧任务或 STOP 预算。

## 最小工作方式

1. 从实际本地 AGENTS、ACTIVE_STATE 顶部当前块和具体目标开始，核对实际目录、Git 身份与受影响状态。GitHub 按需核对，不默认读取所有历史、Sources 或日志。
2. Codex 在目标和权限内自主规划、实现、调试、定向验证、代码审查、工程验收和记录。普通失败在范围内修复，不等待网页 GPT 派单、A–D 发布或网页终验。
3. 依据实际代码、适用标准和证据验收，不倒改冻结 AC。自测、Codex 审查、外部独立审查、Owner 接受和正式发布分开；自己的复查不能称为独立审查，不要求逐项多模型审核。
4. 保留有效功能、原始失败、accepted ADR、隐私、鉴权及 Safety/no-processing 边界。只复核受影响范围；未运行写 NOT_RUN，未核实写 UNKNOWN。
5. 在有意义的节点记录目标、改动、代码身份、检查、未完成项与下一步，通过已授权普通 Git 操作同步脱敏副本。检查整个待推提交范围，不夹带原 dirty/staged/untracked、私人历史或 LOCAL_ONLY 原件。

相关验证仍须绑定最终候选及实际序列化/消费行为；会话续接保持同一已批准目标，不擅改冻结目标或标准。原目标缺陷优先修复，新增范围另按 Owner 批准目标处理。受保护实体、真值链和发布逻辑在未获针对性授权前保持不变。

## 边界与停点

Owner 保留产品定位、重大功能和架构、不可逆操作、真实用户/生产数据、设备与外部服务、费用、重大版本及正式发布。权限不清或实质风险只暂停相关工作，提出具体问题与选项；无关已授权工作继续。Web GPT 是按需顾问，咨询由 Owner 发起。

G2、APK/ADB、claim/ledger、一次性额度和平台组织策略保持；不退款、不重置、不复活耗尽预算。不盲 pull/reset/rebase/stash/clean/prune/force，不删除旧版本、备份、数据库、worktree 或原证。

按当前目标的完成条件或真实门禁停止，不把“等待网页验收”设为日常工程继续条件。治理同步完成不等于产品通过，也不自动启动新产品目标。
