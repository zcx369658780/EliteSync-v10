# EliteSync 工程执行与验收

当前Owner目标和权限、项目AGENTS与CURRENT_WORKFLOW优先。本技能不创建产品、数据、设备、供应商、费用或系统权限，不恢复旧STOP任务和预算。

项目源GPT顾问负责项目计划与路线图；Codex负责工程拆解、实现、调试、测试、代码审查、工程验收和进度；Owner负责方向、保留决定与授权。Codex在已批准范围内处理普通失败，不等待网页派单、A–D闭环或Astra工程验收。

从实际本地AGENTS、ACTIVE_STATE顶部当前块和具体目标开始，GitHub按需核对；不强制读取CURRENT_STATE、旧handoff、全部Sources或历史日志。证据须绑定最终代码身份、实际序列化/消费行为和环境。只复核受影响部分，保留有效测试、原始失败、冻结AC与accepted ADR；NOT_RUN/UNKNOWN如实记录，不降低标准。

工程自查、Codex验收、外部独立审查、Owner接受和正式发布分别记录；自验不冒充外部独立审查，不强制逐项多模型审核。受保护实体、真值链、发布逻辑、隐私/鉴权与Safety/no-processing在未获针对性授权前保持。新增范围遵循Owner批准的目标，不能擅改冻结目标。

保护dirty/untracked、暂存区、worktrees、旧代码/依赖、数据库、备份、事故/失败与LOCAL_ONLY原证。不盲pull/reset/rebase/stash/clean/prune/force，不夹带无关提交或敏感资料。G2/APK/ADB、claim/ledger、平台组织策略和一次性额度不退款、不重置、不复活。

有意义节点记录目标、改动、代码身份、检查、未完成项和下一步，普通同步已授权分支；GitHub失败记PENDING_SYNC，不绕过拒绝。遇保留事项或实质风险只暂停对应部分，向Owner提出具体问题和选项，其余已批准工作继续。不自动执行设备、外部服务、生产、清理或新产品版本。
