# EliteSync V2｜NEW-PC-01：评论作者撤回本人评论的展示——顾问审阅V0.1

日期：2026-11-19（Asia/Singapore）  
状态：`ADVISOR_PROPOSAL / NEW_PC01_OWNER_REVIEW_PENDING / NO_NEW_ENGINEERING_AUTHORITY`  
原则：**评论作者撤回自己的评论**与[NEW-PC-02作品作者隐藏他人评论的方向性接受](../decisions/OWNER_V2_NEW_PC02_AUTHOR_CONTROL_THIRD_PARTY_COMMENT_DISPLAY_DIRECTION_ACCEPTANCE_20261119.md)属于两种不同权限。

## 0. 决策问题

评论者本人希望撤回自己过去发表的评论时，V2应该提供什么产品层面的能力？当前已接受[HIS-D1](../decisions/OWNER_V2_HIS_D1_D2_HISTORICAL_ACCESS_AND_SNAPSHOTS_20261119.md)原受众/现读权交集、[OBJ-D1](../decisions/OWNER_V2_OBJ_D1_POST_TAKEDOWN_THIRD_PARTY_COMMENTS_ACCEPTANCE_20261119.md)作者撤下与第三方原件独立、[RET-D1/D2](../decisions/OWNER_V2_RET_D1_D2_REVOCATION_DELETION_CONCEPT_ACCEPTANCE_20261119.md)撤权/删除受理/核实完成分离，**尚未接受评论者自行撤回的产品操作权**。本稿不假定已有后台API、合法处理回执或持久性评论存储。

## 1. 供Owner选择的两个新方案（仅顾问建议）

### 方案A：评论作者可主动撤回本人评论的当前对外展示（推荐）

- 评论作者在当前合法身份与该评论所属业务上下文内，能够表达“停止展示本人这条评论”的明确意图；仅在权威操作结果确认后，将其从原可读受众的**作品内展示**中撤下。
- “撤回展示”不等于物理删除评论原文、历史媒体、已被合法留存的安全/申诉记录或已单独授权的其它副本。对于真实删除请求仍按RET-D1/D2另行处理。
- 作者不能以撤回自己的评论自动撤回其它人的独立回复、重设作品受众或改写其历史评价。被撤回评论与其回复、引用、旧通知的具体保留/展示方式仍单独讨论。
- 操作UNKNOWN先只读权威核验，不假称撤回成功，不自动重复提交。若合法权限无法核验则安全退出；不显示失权内容。
- 与NEW-PC-02独立：作品作者隐藏他人的评论，不妨碍评论者在有权且存在实际能力时处理自己的评论；反过来也不赋予评论者管理作品权限。

**优点**：更符合评论者对自身表达的控制，减少因关系变化而保留不愿再公开发言的摩擦。  
**代价**：需要将外显撤回与合法保留、回复引用、恢复/申诉及安全证据分离，未来才可实现与验证。

### 方案B：暂不设计直接撤回操作，只保留真实合法请求渠道

- 评论者不能在V2首期通过单条评论上的自助动作直接撤回展示；仅可通过届时确实存在、能够合法受理的渠道提出请求。
- 不创建假的“删除已受理”按钮或保证时限。若涉及适用法定权利，应提供实际可达的受理渠道，而非因APP不提供按钮就剥夺权利。

**优点**：首期产品与工程路径更简单。  
**代价**：评论者控制自身发言的摩擦增加，后续可能仍需增加此能力。

## 2. 推荐Owner只确认的最小概念范围（未获确认）

建议采用**NEW-PC-01方案A**作为未来产品方向，仅确认“评论者可以撤回**本人评论的当前作品内对外展示**，不等于永久删除第三方回复或合法独立留存”。**是否纳入V2首期、具体执行状态/API/历史恢复不随方向批准自动确定。**

本次不顺带预先批准以下四类细则：
1. 回复树与引用：原评论撤回后是否以不泄密占位维持讨论结构、关联回复和已发通知如何处理；
2. 恢复与编辑：允许重新显示还是要求重新发表、编辑历史如何处理；
3. Safety/法律：举报、申诉、合法必要留存、保留期限与真正删除范围；
4. 操作与工程：身份验证、原受众和现有权利核对、媒体URL/缓存、跨设备传播、真实回执和幂等机制。

## 3. 与首期范围NEW-PC-03的关系

`NEW-PC-01`只讨论**撤回当前展示的产品权利**；`NEW-PC-03`单独决定APP首期优先有哪些“删除请求”入口，不应通过这项决定偷偷宣称已经具备物理删除、法定处理渠道或真实受理机制。即使接受A，当前无真实接口时也不能标成APP已可使用。

## 4. 顾问建议的下一步（不是任务单）

只请Owner决定是否接受**NEW-PC-01方案A的方向**，不同时打包批准NEW-PC-03或其它未决细节。若获明确接受，另立具名Owner决定，再审`NEW-PC-03`的首期用户入口范围。未来若要落地，必须先另行授权真实工程审计并核适用合法依据。
