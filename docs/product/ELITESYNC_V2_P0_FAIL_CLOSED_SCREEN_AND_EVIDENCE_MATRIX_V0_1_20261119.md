## 2. 准入证据的最小清单（非当前测试计划）

将来每一项真正需要解除阻断时，至少保存：
1. **本地现行软件身份**：实际工作区根、分支/提交、APP/API/DB与提供者状态；不得以本治理分支充当代码版本。
2. **固定真实场景**：身份/双方账号、设备、资料来源、用途、受众/Block、历史版本、是否具备真实供应商；并记录原1011804基线与新候选的区别。
3. **实际业务权威回执**：包括成功、失败、UNKNOWN/NOT_RUN、重试安全条件及失权恢复；拒绝和撤销也要覆盖。
4. **D/I/N/A/W与无障碍**：必要决定、字段输入、额外导航、自动动作、等待分别统计，并证实字体放大、读屏、系统Back、减少动效、异常安全区。
5. **素材与访问权证据**：原PNG/SVG身份、媒体/深链/缓存/历史评论受众验证，隐私与合法第三方权利不因截图泄漏。
