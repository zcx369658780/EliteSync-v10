## 视觉原则（已经Owner认可的方向）
- **首屏少信息、清楚当下任务**，构成主义组织内容优先级，不为装饰增加阅读成本；二次元人物/生活场景只表达情境。
- 主色深青、蓝绿、灰蓝；大面积背景为低刺激淡绿/淡蓝/灰青，避免高亮白红强反差。设计需要最终验证文字对比度和夜间模式，**没有已冻结的Hex品牌色**。
- 带图Lifestyle交互持续保留；正式五场景和每题三选项不得被任意新增兴趣维度替换；示例图文不等于正式题库。
- 首页采用内容优先的构图，官方精选与用户作品清晰区分；访客只看到官方允许内容；匹配入口辅助且低干扰。
- Match准备按服务端真实事实显示需补项；核验供应商未接入时禁用正式报名、严禁显示已认证。

## 页面状态清单
| 页面/状态 | 当前用途 | 主操作 / 显示 | 恢复与权限 |
|---|---|---|---|
| A1 欢迎 | 可跳过的首次探索入口 | 开始探索；次级“以后再说” | 跳过后返回首页，未来真实匹配仍需补全 |
| A2 单题 | 五场景题之一 | 带图三选项；保存成功后自动下一题（顾问建议） | 保存失败停留本题 |
| A2 已登录精选 | 浏览本人有权内容 | 官方精选/专题、独立用户公开作品区；精选/好友 | 当前登录、受众及Block判断 |
| A2 访客精选 | 只读官方公开内容 | 官方编辑正文；登录/注册 | 不显示用户公开作品及可互动状态 |
| A2 匹配部分完成 | 补当前必要条件 | 继续尚未完成的Lifestyle或必要资料 | 不能从未完成状态真实报名 |
| A2 匹配内部准备完成 | 告知外部依赖 | 服务未接入，正式报名不可用 | 不能显示假核验PASS；星盘可选 |
| A3 保存中 | 展示保存进度 | 保留已选图文，防重复发送 | 未收到确认之前不记完成 |
| A3 网络失败 | 恢复提交 | 显示“未保存”、重试/稍后完成 | 不强迫重填选择 |
| A3 返回改选 | 允许纠正答案 | 选择另一项，成功保存后刷新有效进度 | 冲突按现有后端合同检查，不覆盖新版本 |
| A3 返回继续 | 中断后继续 | 当前账号已确认进度，定位下一题 | 不跨账号显示缓存或错误的已完成状态 |

## 从A3进入A4的设计输入
A4目标：`本轮提案本人决定 → 双方条件满足 → Connection双方明确决定 → Messaging Consent双方明确决定 → 有权聊天`。各阶段应有清晰等待/拒绝/过期/撤销/账号隔离状态，前一步接受不产生下一阶段同意。**A4仍属顾问提案，不是工程任务。**
