## 1. O10-R1：一屏一目的、一主操作、分层披露（顾问建议）

每个关键页面需要在首屏准确回答：
1. **PURPOSE：来这里做什么？**
2. **CURRENT_STATE：现在实际处于什么可验证状态？**
3. **PRIMARY_ACTION：当前唯一需要被强突出显示的合法下一步是什么？**
4. **SECONDARY_ACTIONS：必要的拒绝/撤回/返回/反馈在哪里？**
5. **AUTHORITY / RETURN / RECOVERY：状态依据谁、跨页完成后回哪里、出错怎么办？**

主操作强调不等于一屏只有一个可点控件；低频但重要的拒绝、撤回、权限管理不能被埋在深层菜单。构成主义几何分块以**减少阅读负担和导航寻找**为唯一正当性，非铺满全屏装饰。二次元插画帮助理解当前情景，不能挤压正文、选项或安全信息。

### 五类关键页面的统一焦点

| 页面/场景 | 第一眼的重点 | 主操作/状态 | 禁止视觉误导 |
|---|---|---|---|
| Lifestyle单题 | 场景图与当题问题 | 三个可辨认且可读的选项 | 动画遮字；网络保存失败却自动跳下一题 |
| 首页精选/好友 | 当前有权阅读的内容 | 官方/用户内容分域、切换频道 | 访客看到站内用户作品的敏感缩略图；编辑推荐暗中升权 |
| 匹配准备 | 当前可完成的缺项 vs 不可用依赖 | 继续Lifestyle/填写必要字段；不可用供应商明确阻断真实报名 | 把真实核验未接入画成“差一步即可报名” |
| 消息聊天/通知 | 聊天默认入口、当前有效待办 | 进入当前合法会话/具名待办 | 已读=业务完成；旧通知一键接受 |
| 我的/资料与异常 | 本人资料来源/用途/发布版本或安全错误状态 | 合法编辑/确认发布/只读查结果/安全返回 | 保存自动公开；错误页敏感内容为截图而滞留 |

## 2. O10-R2：色彩、插画、动效的低刺激检查（顾问建议）

- **背景**：继续柔和淡绿/淡蓝/灰青，避免强亮纯白大面积与高饱和红作为长期视觉主调；深青、蓝绿色强调主操作，具体色值后续正式视觉阶段确定。
- **信息密度**：首屏优先主要任务卡，普通设置、解释和次级指标用按需展开；不在Home堆叠多行匹配状态，也不将“我的”变成权限表格。
- **选择状态**：Lifestyle图文三选项须有文字可辨的选中标志；不只依靠颜色、不覆盖选项文本，图像缺失时仍可识别题目与答案。
- **动效**：几何转场/非写实“倒影变化”只是备选视觉语言；动画不能替代服务器回执。系统减少动态效果时改为无过渡或简化过渡，不影响页面状态判读、Back和确认。
- **字与点击区域**：应在将来的字体放大/小屏/横竖屏/读屏测试中保证内容和主要操作不被遮挡；此草案不凭空冻结具体字号或触控像素值。
- **状态色**：成功、警告、未知、已失权均需有文字与图形双重提示；UNKNOWN不得仅凭颜色暗示提交失败或成功。

## 3. O12-R1：未来可用性QA必须按D/I/N/A/W分别计量（顾问建议）

沿用[注册到聊天V0.2](ELITESYNC_V2_REGISTER_TO_CHAT_USER_JOURNEY_V0_2.md)口径：
- **D**：用户必须明确做的独立业务决定或授权（不应为了降低点击而删除）。
- **I**：真实需要输入的字段/题目；已有可合法复用的资料不重复收集。
- **N**：额外导航或寻找入口操作（优先减少）。
- **A**：系统自动合法预填、计算、重验、状态刷新（不计入用户动作）。
- **W**：网络、核验供应商、对方独立决定等等待（单独观察，不伪装为用户点击成本）。

最低检查内容：每条旅程固定起始账号、设备、权限、资料、版本、是否真实供应商已接入；分别记录现有工程实际观测与V2未来设计目标。**不把顾问预算当运行时通过结果，不给没有证据的“3秒”或“4步全流程”硬承诺。**

## 4. O12-R2：无障碍与异常检验清单（顾问建议）

- 用**字体放大、屏幕阅读器、系统减少动态效果、横竖屏和小屏安全区**逐页检查：页面目的和状态是否能读到，主操作是否易触达，拒绝/撤销/退出是否有文字可达且不被装饰遮挡。
- 图像内容必须有可理解的替代文字或等价题目描述；一旦图片丢失，Lifestyle三选项仍可完成。
- 安全错误摘要可读、可复制，不含已失权私密；进入反馈、预览附件、取消提交均可使用Back，且不能自动发送。
- 选中态/权限受限态/UNKNOWN不能仅靠视觉颜色区分，最终对比度及触控目标应在正式UI规范阶段按适用平台标准核验。
- 每一项QA必须分别记录`PASS / FAIL / NOT_RUN / UNKNOWN`及证据；未执行全部保持`NOT_RUN`，**不能将此清单本身标记为测试PASS**。
