# EliteSync V2｜A5-4 四入口统一交互检查（顾问评审草案）

日期：2026-11-18。来源：此前Owner确认的V2产品决定、A1–A5-3视觉与交互设计、A5-3精确低保真图；本文件为顾问审阅，**不是运行时测试或工程验收**。

## A. Owner已确认并需要保留的业务边界

- 四个一级入口：**首页／匹配／消息／我的**；首页精选／好友；消息聊天／通知默认聊天，未读独立，当前有效待办优先。
- 访客仅可阅读允许公开的官方精选与专题正文；不能读取用户作品或好友动态，不能提交站内评论、点赞、收藏、举报及反馈。登录用户访问用户作品仍须按受众、Block等权限实时判断。
- Lifestyle五场景、每题三选项，注册后可跳过，正式真实匹配必须完成；正式真实匹配还须真实实人核验，目前供应商**未接入**。星盘不构成硬门槛。
- Match / Connection / Messaging Consent / Conversation / Relationship 各自独立，双方分别决定；从提案到许可可以连续展示但不能自动推进下一项授权。
- 个人主头像昵称在本人社交／匹配形象预览可以合法复用；对外展示受众及发布版本独立。
- 视觉方向：低信息密度的构成主义组织 + 适度二次元生活场景；淡绿／淡蓝／灰青底色、深青低刺激重点色，夜间友好但文字对比仍需测试。

## B. 页面结构检查（顾问方案）

| 顶层入口 | 单一主任务 | 典型内容 | 最重要的状态/权限校验 |
|---|---|---|---|
| 首页 | 浏览有权内容 | 官方精选、用户作品（已登录）、好友 | PUBLIC_EDITORIAL / PUBLIC_AUTHENTICATED / FRIENDS 的服务端受众；访客不可互动 |
| 匹配 | 资格准备与独立本人关系决定 | 当前条件、报名、提案、Connection、消息许可 | 真实核验供应商未接入，不能开放真实报名；依当前状态一步步显示 |

| 我的 | 编辑本人资料、偏好、形象、权限 | 资料卡、Lifestyle、自我探索、社交与内容、隐私授权 | 基础事实/用途授权/展示受众/已发布快照分离 |

## C. 三条跨页路径与重复操作

1. **首页→匹配**：底部匹配和首页低干扰匹配入口应指向同一匹配业务上下文，不能各有一套独立准备状态。用户点进入后读取当前资格；合法主操作只展示一项。
2. **匹配→编辑缺失资料→返回**：直接访问原字段权威页，在允许的用途范围内预填，保存成功返回原匹配任务并重算准备状态；失败不假成功；返回不触发自动报名或公开。
3. **消息通知→原业务页面**：通知卡只负责导航，目标页必须重验账号、Block、受众、事件当前有效版本、双方Connection/消息许可等适用权限；本人在该页明确决定，通知不会代替确认。

## E. 建议的设计验收场景（目标，未执行）

- 访客从官方精选进入用户作品链接：只能得到权限允许的访问结果，不显示用户内容/缓存/互动；有权登录后重新判断。
- Lifestyle 2/5，资料缺失，核验服务未接入：仅能继续有效准备，真实报名禁用；不生成真实提案。
- 从匹配补城市：进入原字段编辑→保存→返回原匹配位置；失败重试不刷新成“已完成”，不自动报名。
- 通知待办已读但尚未决定：待办不因已读消失；过期后不能再执行旧操作。
- 双方Connection成立但一方消息许可未给：联系人不进入可聊列表，不能向会话写入消息。
- 切换账号或Block：不显示前一账号的聊天、通知、提案和资料缓存。
