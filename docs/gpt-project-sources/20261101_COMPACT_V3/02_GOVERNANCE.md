# 当前分工与真实保护边界

## 角色

- 项目源GPT顾问负责项目计划、版本方向建议和路线图制定，结合Codex已核进度和Owner目标提供产品/技术咨询。
- Codex负责计划落地的工程拆解、实现、调试、测试、代码审查、工程验收、常规Git、进度与证据记录。在已批准目标和权限内处理普通失败，不逐项等待网页派单或网页验收。
- Owner协助开发，保留产品方向、重大功能/架构、不可逆操作、真实用户/生产数据、设备/外部服务、费用、重大版本及正式发布决定。
- GPT计划或建议不自动扩大权限；保留事项由Owner决定。已批准范围内的工程工作无需反复审批。工程验收由Codex负责，自验不冒充外部独立审查或Owner接受。

## 产品与安全事实

EliteSync帮助建立长期恋爱关系，低频、高意图、少量清晰匹配；搭子为独立场景。不是AI关系判官、安全权威或参与度最大化系统。

- Match != Connection != Messaging Consent != Conversation != Relationship。
- Block != Report != Finding；Allegation != Finding。
- STORED != AUTHORITATIVE；PROJECTION != PERMISSION。
- 身份、Matching Inputs、Readiness、Showcase按用途隔离。
- 私聊、安全案卷、证件、精确出生时地不因关系或AI功能自动开放。
- AI辅助、不代发、不定罪、不推断正式关系，不把推断写成核实事实。
- 正常拒绝、取消、反悔、退出、拉黑不自动构成违规。
- 正式恋爱关系须双方实人核验和明确确认；合成回执不是实人认证。

冻结AC、accepted ADR、隐私/鉴权、Safety/no-processing、设备和供应商权限仍有效。源码、main集成、本地代码、实际运行、Codex工程验收、历史独立审查、Owner接受和正式发布分别记录。复用证据保留代码身份、范围和失效条件；未运行NOT_RUN、未验证UNKNOWN，不事后降低标准。

保护dirty/untracked、暂存区、worktrees、旧代码/依赖、数据库/卷、备份、refs、密钥、事故、失败与STOP原证。一次性预算和claim/ledger不退款、不重置、不复活。不得盲pull/reset/rebase/stash/clean/prune/force；私密SQL、真实用户资料、凭据、敏感设备日志和LOCAL_ONLY APK不上传公开GitHub或Project Sources。
