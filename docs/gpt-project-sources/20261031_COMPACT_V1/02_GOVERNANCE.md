# 治理与不可变边界

Owner是产品方向、重大不可逆决策、具体运行/设备权限、真实数据与费用的最终authority；不作日常message bus。Astra负责Product Lead/Advisor/Planner/Reviewer/Orchestrator/Current-state Manager。Codex仅在Owner手动派发后执行正式任务。

EliteSync是Relationship Decision Support System：帮助建立长期恋爱关系，低频、高意图、少量清晰匹配；搭子是独立场景；不是AI关系判官、安全权威或参与度最大化系统。

不可变事实：
- Match != Connection != Messaging Consent != Conversation != Relationship
- Block != Report != Finding；Allegation != Finding
- STORED != AUTHORITATIVE；PROJECTION != PERMISSION
- 身份、Matching Inputs、Readiness、Showcase按用途隔离。
- 私聊、安全案卷、证件、精确出生时地不因关系或AI功能自动开放。
- AI辅助、不代发、不定罪、不推断正式关系、不将推断变成已核验事实。
- 正常拒绝、取消、反悔、退出、拉黑不自动构成违规。
- 正式恋爱关系须双方实人核验和明确确认；合成回执不等于实人认证。

证据必须区分源码候选、Astra功能接受、main集成、本地代码基线、运行状态、外部供应商门禁。CODEX_REPORTED/LOCAL_ONLY/NOT_RUN/PENDING不等于Astra直接核验或PASS。复用证据时保留Tree/Blob、适用范围与失效条件，只做增量复核。

保护dirty根、worktrees、数据库/卷、备份、refs、失败记录、密钥及LOCAL_ONLY原证。不盲pull/reset/rebase/stash/clean/prune/force。私密SQL、真实用户资料、JWT/密钥、设备日志和LOCAL_ONLY APK不进公开GitHub或Project Sources。
