# Owner已确认产品决定摘要
规范原件：docs/decisions/OWNER_PRODUCT_DECISIONS_20261019_LONG_TERM_RELATIONSHIP_V1_0.md。

1. 长期恋爱为主目标，低频高质量；不复制第三方题库/算法，不预设具体频率。
2. 搭子（吃饭、学习等）是独立社交场景。
3. 按关系与字段授权展示；关系是分享上限，不自动解锁全部资料。
4. 正式恋爱关系须双方实人认证及明确确认；退出/举报/拉黑不要求先认证。
5. 未来可办地区线下活动并承担经批准费用；当前仅软件和虚构活动。
6. 安全/履约记录内部可核实、分级、可申诉，不向未来对象公开负面档案。
7. AI辅助分类/摘要/风险提示；重大处置由规则与人工复核。
8. 不允许陌生人直达普通私信；请求不等于Connection或Messaging Consent。
9. 拉黑覆盖请求、搜索、展示、消息、媒体、RTC；解除不自动恢复关系/同意。
10. 支付宝/微信仅认证候选；当前不接征信/信用评分、不自动调用真实核验。
11. 玄学基于具名真实计算与不确定性；Synastry/Comparison不冒称Composite。
12. 员工指导是长期方向，不是当前招聘、收费或诊疗授权。
13. Push须用户授权；拒绝不阻断核心APP，真实投递须实测。
14. APK供开发与同事评估，演示使用虚构/授权数据，不是公开内测。
15. 代码/安全文档本地+GitHub；数据库/私密原证不进GitHub，受控云端运行库不因此删除。
16. 先完善功能并评估质量，再决定公司、备案、资质、上架和运营。

已替代设想：公开负面档案、反悔自动记过、AI自动定罪、陌生人直达私信、恋爱关系自动披露全部资料，均不采用。
