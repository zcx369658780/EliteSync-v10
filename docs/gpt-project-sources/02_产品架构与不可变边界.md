# EliteSync v10｜产品架构与不可变边界

项目源版本：2026-09-27。产品设计正文与 Owner 接受记录分别见本包 `06_新版本APP功能设计正文_已接受.md`、`07_新版本APP功能设计Owner接受记录.md`；设计正文的 Git blob 为 `b72ed9ec851d44aba7be65883186cb275fab22d1`。产品接受不等于代码、数据库或发布完成。

EliteSync 的目标是审慎、可解释、以用户控制为先的关系决策支持。`Match != Connection != Conversation != Relationship`：匹配不自动建立 Connection，Connection 不自动开启 Conversation，对话行为不自动建立 Relationship。AI 不能成为关系真相、过错、Safety finding 或自动匹配裁判。信息权威取决于含义、来源、用途与生命周期，不取决于哪个表保存了数据。

MVP 顶层目标为 `Home | Progress | Messages | Me`；Discover 退出 MVP 顶层并在 Phase 2 作为 Explore/Support Library 候选。MVP 不建立全球公开 Profile；Private Identity、Matching Inputs、Readiness、Showcase 分开。Showcase 的 candidate/connection 范围不使身份信息自动公开。Privacy、Safety、User Control 优先；Block、Report、Allegation、Finding、UNKNOWN 各有不同含义。私密 Conversation 不默认进入 AI 训练、排名、普通兼容性或公开声誉。

已接受设计中的可见范围包括 `PUBLIC_EDITORIAL`、`ACCOUNT_PRIVATE`、`PRIVATE_IDENTITY`、`READINESS_RESTRICTED`、`MATCH_PURPOSE_LIMITED`、`SHOWCASE_CANDIDATE_SCOPED`、`CONNECTION_SCOPED`、`CONVERSATION_SHARED_PRIVATE`、`RELATIONSHIP_SHARED_PRIVATE`、`USER_PRIVATE_REFLECTION`、`AI_DERIVED_PRIVATE`、`SAFETY_RESTRICTED`、`OPERATIONAL_MINIMUM`。Private Identity 不自动进 Showcase，Safety evidence 不进普通 Compatibility/Ranking，AI 推断不变成已核实事实。Product Connection 的精确状态/理由/schema 仍消费对应已接受技术契约；`STORED != AUTHORITATIVE`、`PROJECTION != PERMISSION`、`ROUTE IDENTITY != CONSENT`。既有 Binding Model A、结构诊断、理由和 cross-field/terminal/invalidation 规则不因本摘要重写。

在线 Conversation 的 live read/send 仍须核对当前有效 Connection 与独立消息同意，发送时重查；本地 Match 投影或旧路由成功测试不授予消息权限。Owner 后续接受按账户加密的私密缓存离线只读方向：登录有效及其他条件满足时可读已保存会话、消息、媒体和草稿，离线不得发送；在线登录期 15 天，从最后一次成功在线登录起 30 天未再次登录须清理相应加密私密内容，第 16～30 天的离线只读不恢复在线发送权。具体凭据、可靠时间、撤权传播及清理实现尚未证明。详见实时 `PRODUCT_DECISIONS.md`。

Owner 指定账号回填最低含账号、**现有密码哈希**、昵称、生日、出生地点；不索取明文密码。当前两处已核定同账号出生地点候选按 `users.private_birth_place` 优先、缺失时取 `user_astro_profiles.birth_place`；两库间账号集合与来源优先级仍待隔离恢复后的逐对象核对和 Owner 决定。

保留既有 accepted ADR、法律/Safety/no-processing、未解除 UNKNOWN、README 已耗预算及旧仓库边界。产品源摘要不创造真实数据、招募研究、analytics、Safety Operations、生产持久化或部署权限。
