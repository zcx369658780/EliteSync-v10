# EliteSync 10.x｜APP功能设计导读与2026-10-19增量

本页是新导读，不是改写2026-09-12设计。06/07原件保持；本次新增Owner方向见08，路线见09。

## 原设计继续保留

Home/Progress/Messages/Me目标IA；逐步注册/准备；Identity/Matching Inputs/Readiness/Showcase用途分离；canonical Match；独立Connection、Messaging Consent、Conversation、Relationship；不以单一兼容总分和AI关系判断替代用户；可解释、隐私最小通知、统一空/加载/离线/失效状态和明确退出。

原设计中的Relationship/Explore等曾排Phase 2，personality/astrology曾在Later。不能依据这些旧排程否定后来已接受三盘/动态盘，也不能阻止本次Owner确认的独立搭子/好友社区/正式恋爱关系进入后续功能包。

## 本次增量是什么

长期恋爱关系是主线，独立搭子不是约会后的附属。社区以关系受众组织；正式恋爱需双方实人核验及明确确认；深入资料由本人按字段分享。新增内部公平履约/安全流程、未来平台活动与详细解读/员工指导方向，Push要用户同意。

陌生人普通私信、AI自动定罪、公开负面恋爱档案、信用评分替代关系判断不采用。请求箱是可选前置邀请，不替代CN/MC。拉黑阻断联系，隐藏会话不等于拉黑或注销。

这些是新的规划输入，不是“当前所有功能已存在”。账号隐私/注销、Buddy真实业务、社区深度、Push、历史恢复、签名/升级和外部Web仍按各自缺口处理。
