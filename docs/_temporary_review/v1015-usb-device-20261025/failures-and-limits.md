- First owned SFU startup failed closed when a cold authority request exceeded its existing timeout. The missing local RTC switch was set in task-owned environment, the authority warmed, and the owned SFU restarted; original logs remain.
- Initial synthetic browser preflights accepted server-provided default ICE configuration and produced server-reflexive candidates. This is not process-tree NO_NETWORK evidence; destination traffic was not packet-captured. They were stopped. The later peer explicitly used an empty ICE-server list, as the app already does; it still timed out with no nominated pair or RTP. No system/firewall/route/browser security restriction was relaxed. Do not claim all initial peer traffic was confined to loopback.
- Ordinary Android build exit0 after Kotlin incremental-cache errors triggered its compiler fallback. Deprecation and native-symbol stripping warnings remain. No new tool/SDK was installed; existing tools/caches were copied into the owned build root. Offline dependency resolution is not a proof of no network for the whole process tree.
- Early device harnesses assumed immediate navigation or keyboard animation completion; assertions failed. Original output is retained. The visible send action was later confirmed by app UI and peer API with one persisted row. No duplicate logical message was submitted to hide an unknown result.
- The first revoke harness reached its authorization assertions, then exited1 because it incorrectly expected an authorized call-detail read after revocation; the real API returned404. A corrected fresh call recorded all HTTP statuses and used a guarded owned-database read for terminal state, exit0. The original exit1 is retained.
- The notification harness wrongly expected an unchanged live preferences page after OS runtime-permission revocation. Android restarted the app into its login gate. The actual permission=false, locked UI, absent private text, and persisted preferences were checked separately; no product permission was weakened. The initial exit1 is retained.
- Phone camera/media toggles, successful audio/video flow, same-call media reconnect, deliberately delayed old heartbeat/endCall on a physical connection, and physical AEC remain NOT_RUN or NOT_PROVEN. The accepted 95/11 unit runs are REUSED_EVIDENCE and are not 106 distinct cases.

That token had not previously carried a media session. This does not establish a successful call's reconnect or five-second flowing-media stop.
- All new synthetic sessions/tokens were revoked through the existing service in the guarded new database; zero active calls remain. Local app is stopped at its login gate. Task-owned services, browser endpoint and Gradle daemon stopped; owned ADB forwards removed. Containers/volume, SQL/APK and all prior evidence remain.
