# Historical Archive

Files under this directory are preserved historical evidence.

They are not EliteSync-v10 architecture authority and should not guide v10 design decisions. Historical migration, source archaeology, runtime preparation, and validation records may be consulted only as bounded evidence when a current task explicitly needs them.

Archiving a file preserves it; it does not validate, reactivate, or promote its assumptions.

- `migration-9x/`: overall 9.x-to-v10 migration plans, manifests, preflight, and completion evidence.
- `runtime-history/`: historical local runtime, dependency, Laravel, MariaDB, and database preparation evidence.
- `source-migration/`: historical backend, Flutter, Android, and source-validation evidence.
