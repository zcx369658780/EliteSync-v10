# 用户文案映射

| 页面或状态 | 原文案 | 当前文案 | 状态来源 |
|---|---|---|---|
| 首页账号 | 账号可用 | 欢迎回来 | B2 `/user-state` 的账号状态为 `AVAILABLE` |
| 首页账号受限 | 账号状态暂不可用 | 当前账号受限，请查看账号状态 | B2 `/user-state` 的账号状态为 `UNAVAILABLE` |
| 首页账号未知 | 未知状态码 | 账号状态暂时无法确认 | B2 `/user-state` 未识别或无法读取 |
| 首页主按钮 | 查看我的进展 | 查看匹配 | B2 `next_actions` 中的下一步 |
| 匹配空结果 | 本轮暂无候选，不代表被拒绝 | 本轮暂无匹配 | B2 轮次状态 `NO_CANDIDATE` |
| 轮次失败 | 轮次处理失败，可刷新查看恢复状态 | 本轮处理遇到问题，请稍后刷新 | B2 轮次状态 `FAILED` |
| 准备完成 | 已完成当前必要准备，可自行决定是否参与 | 准备已完成 | ProfileReadinessService 投影 |
| 资料待确认 | 请进入我的匹配输入，确认本人资料及双方偏好 | 请确认匹配资料与偏好 | ProfileReadinessService 投影 |
| 参与资格未知 | 当前暂不符合参与条件，请检查准备状态或稍后刷新 | 暂时无法确认参与资格，请刷新 | B2 readiness code 未识别 |
| 参与结果 | 已参与 / 生效 | 已参与 | B2 参与状态 |
| 候选决定 | 等待双方独立回应 | 等待双方回应 | Match proposal 状态及双方决定 |
| 双方决定 | 双方已选择，连接与消息同意仍需独立确认 | 双方已接受 | Match proposal 状态，Connection 与消息许可仍由独立入口处理 |
| 结果读取失败 | 提案读取未完成，请刷新 | 匹配结果暂时无法加载，请刷新 | 既有匹配结果读取错误 |
| 自动化任务 | 本轮尝试已用完，请查看当前状态 | 本轮未能完成，请查看状态 | B2 自动化任务结果 `RETRY_EXHAUSTED` |
| 自动化入口状态 | 尚未授权 | 尚未开启 | B2 自动化授权状态 `OFF` |
| 匹配说明 | 无固定说明 | 首次确认前显示简短匹配说明 | 复用 matching-input 的服务端 `confirmation_version` 与 profile hash |
| 会话空状态 | 暂无服务端可读取会话，请刷新或先完成双方连接和消息同意 | 暂无会话 | 当前用户有权读取的会话列表 |
| 搭子发现空状态 | 当前没有符合条件的公开搭子 | 暂未找到搭子，试试其他城市或活动类型 | Buddy discovery 当前筛选结果 |

自动化授权生命周期页、匹配页与我的页的入口均只操作现有 B2 合同。首次匹配说明确认取消或确认过程中切换账号时不会提交资料，同一版本已确认后不重复展示。

来源映射的完整工程变更索引见本目录的 `COPY_CHANGE_MAP.json`。本表仅列用户可见文案与文案状态来源，不将代码结构调整记为文案变更。

## 实际APP发现后的补充收口

| 页面 | 原文案或表现 | 最终表现 | 状态来源 |
|---|---|---|---|
| 首次使用引导 | 先从慢约进展开始 | 查看匹配，介绍当前匹配入口 | 原首次引导完成、跳过及重看记录 |
| 匹配资料入口 | 我的匹配输入 | 匹配资料与偏好 | 原 matching-inputs 版本化确认 |
| 自动化说明 | 授权说明 weekly_consent_v1 | 当前授权说明 | consent_version 继续用于现有授权请求 |
| 头像 | 仅现有获准关系上下文可见 | 仅向已获准的人展示 | 原头像受众权限 |
| 通知页 | 常驻四条提醒示例和重复核验字幕 | 展示实际通知与必要操作 | 原通知读取、权限核验与已读合同 |
| 通知正文 | 请查看当前有权状态 | 点开查看详情 | 既有最小化站内预览 |
| 已发消息 | 服务器已保存，未读 | 已发送，未读 | 已持久化的本人消息 |

常驻匹配、权限与工具说明收纳于我的→权限与说明。授权和关系决定保留当次操作所需的确认。
