# 用户可见文案审查清单

| 页面范围 | 审查结果 | 处理记录 |
|---|---|---|
| 首页 | 完成 | 账号可用改为欢迎语，受限、未知状态分别表达。主入口改为查看匹配。状态仍来自 B2 用户状态 API。 |
| 匹配 | 完成 | 页面标题及底栏改为匹配，轮次、结果、决定和历史使用匹配用语。自动化入口指向 `/user-state`。 |
| 生活方式探索 | 完成 | 选项反馈和进度提示保留，按钮与选中态统一主题配色。 |
| 自动化 | 完成 | 首页状态短句化，一般授权说明集中至我的→权限与说明。单一授权页和明确授权动作保留。 |
| 消息 | 完成 | 会话空状态改为「暂无会话」，离线和前台恢复提示简化。消息读取与站内通知仍分别使用原权限和已读合同。 |
| 我的 | 完成 | 增加醒目的持续参与与自动化入口。原说明入口标题调整为权限与说明，沿用既有页面路由。 |
| Buddy | 完成 | 搜索提示和空结果改为可理解的下一步。类型、城市、活动开放和发布条件仍按现有 Buddy 服务处理。 |
| 社区 | 已静态检查，本版无改动 | 页面继续说明好友受众、自己或双向好友可见、明确选择受众发布及分页行为。原有访问错误仍提示刷新或重新加载。 |

一般匹配、自动化、私密资料、消息、Buddy、社区、工具、举报及账号说明已收纳到「我的→权限与说明」页面。资料受众管理与隐私分享的操作入口保留。匹配页仍可访问报名和候选详情，Match、Connection、Messaging Consent、Conversation 与 Relationship 各自使用原服务事实。

本清单记录静态源码审阅和已执行的定向 Widget / 路由测试范围。它不代表 Owner 实机验收、系统级辅助功能验收或所有通知送达渠道已完成。
