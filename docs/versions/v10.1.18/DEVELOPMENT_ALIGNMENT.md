# v10.1.18开发思路对齐文件

## 1. 当前授权

Owner授权v10.1.18「UI表达与交互一致性收口」。本版基于v10.1.17有限实机反馈，不改变B1/B2/B3历史验收范围。v10.1.17 Owner整体接受仍PENDING，不因本次授权自动改为接受。

## 2. 四项UI主线

1. 清理开发式/程序式文案，保留事实不确定性；
2. 一级「进展」改为「匹配」，聚焦匹配结果和本人行动；
3. 统一按钮和选项各状态配色，修复高亮后文字可读性；
4. 自动化入口可发现，但实际授权/控制只有B2一个规范页面。

## 3. 说明文案

一般持续性说明与长免责声明集中在「我的→权限/说明」。首次参与匹配可展示一次必要简短说明。任何隐私、分享、匹配接受、消息同意、Connection、Relationship或不可逆动作仍保留明确用户决定，不允许静默授权。

## 4. Buddy独立边界

Buddy与恋爱匹配独立。先诊断无法匹配原因；只修复证据明确的UI/路由/配置/API接线缺陷。算法、权重、候选池规则若需要改变，提交报告并等待Owner决定。

## 5. 冷启动与账号隔离

Owner观察到新账号未显示旧账号消息，但冷启动未测。本版必须在同一安装中A登出→B登录→force-stop→cold-start B→A重新登录，核对用户状态、消息、通知、缓存、草稿及离线恢复。Owner手机由Owner自行决定是否再测，Codex不操作。

## 6. 保留产品合同

Match、Connection、Messaging Consent、Conversation、Relationship继续独立。Buddy独立。社区仍为有限场景。四底栏保留。视觉维持低刺激色块/几何构成；不生成新素材。B4、阶段C未授权。
