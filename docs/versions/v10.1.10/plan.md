# v10.1.10 计划：自我认识与特色工具产品化

日期：2026-11-14（北京时间）。状态：TASK_ISSUED。依据：Owner于本会话明确接受v10.1.9并授权进入v10.1.10；范围按2026-11-13 V2.0路线图具体化。

## 1. 目标

把已有 MBTI、本人三盘（本命西洋盘、八字、紫微）、手填动态盘及手填双人盘能力收束为可正常使用、可持久保存、可重读和可管理的特色工具产品。优先补实际断点，不重建已有计算引擎，不以页面存在或单元测试替代真实业务链。

本版遵循“本人可正常使用、重读和管理已选特色工具；计算与解释来源清楚”的用户出口。

## 2. 固定边界

- MBTI是可选自我认识工具，不是心理诊断，不是匹配硬筛选、排序或权威兼容性分数。不得把MBTI中心与既有20题匹配问卷混为一体；不得未经核准复制第三方题库。
- 三盘按当前功能目录既有语义处理：本命西洋盘、八字、紫微。Codex先从当前源码确认实际算法、输入、存储和结果结构；不得因术语相似自行改名、替换或宣称新精度。
- 动态盘及双人盘继续使用用户明确手填/本人已确认的输入。不得读取另一EliteSync账号的出生资料，不新增账号间出生信息授权、好友/CN/MC/Showcase/私聊/通话权限。
- 已有双人盘继续标为Synastry/Comparison等现有准确语义；不得改称Composite，不把已有手填关系盘删除或自动转换。
- 出生时间未知、地点不完整、时区/夏令时、输入纠正、计算失败和部分结果必须如实表达；不得制造精确度。独立盘面精度仍按UNVERIFIED记录，除非有新的独立证据。
- 先真实APP/API/持久数据库链，必要Web管理能力只在当前功能确有后台需求时补齐。禁止以夹具、直接改库、受控成功响应冒充普通产品链。
- 不做新的AI关系推进、跨账号关系解释、自动读取他人出生资料、AI外发、商业服务、支付或供应商接入。
- 不开展公司、内测、运营或正式发布；不合main、不操作手机、不启动v10.1.11。

## 3. 六项验收标准

### AC10-01 MBTI本人使用闭环
从普通APP入口完成当前已支持的MBTI输入/选择、提交或保存、结果读取、历史重读及用户主动更新/重算。区分MBTI与匹配问卷；若当前题目或计算仅为简版，清楚标注实际范围，不自行扩写成完整标准测评。

### AC10-02 本人三盘输入与计算闭环
本人出生资料及必要的时区/地点输入可正常读取、校正和提交；本命西洋盘、八字、紫微分别调用既有真实计算能力，结果结构与当前算法语义一致。处理未知出生时间/缺失输入和失败反馈，不用空态或预制结果冒充计算成功。

### AC10-03 动态盘闭环
使用本人明确提供的动态输入，完成计算、结果读取、重新计算和必要历史版本区分。说明输入来源、时间范围/参数及计算版本；不自动推导或调用其他账号私有出生信息。

### AC10-04 双人盘手填闭环
继续支持手动输入第二对象所需资料并进行既有Synastry/Comparison计算；输入、结果、历史和删除/重算语义清楚。不得跨账号查找、补全或读取对方出生信息；不得宣称Composite。

### AC10-05 持久化、历史与纠错
相关本人输入、计算结果、版本/时间和必要来源信息按既有隐私分类持久化；退出重登、页面重进及必要服务重启后可按权限读回。编辑输入后产生明确新版本或更新语义，不静默覆盖无法追溯的旧结果。不得保存超出功能所需的敏感信息。

### AC10-06 解释、状态与高级参数
基础解释能说明使用了哪些输入、缺失项、算法/来源和不确定性；高级参数与普通结果分层，不把参数存在等同精度验证。加载、无输入、未知出生时间、计算失败、过期/旧版本、离线和权限拒绝均有准确状态及恢复动作。

## 4. 实施方法

- 先做最小源码盘点：定位现有MBTI、三盘、动态盘、双人盘的APP入口、API、服务、持久化表/模型、计算库及定向测试；只记录直接相关文件和已知差距，不递归全库考古。
- 优先复用既有服务、算法和数据结构。若发现关键业务定义/算法来源无法确定，保留UNKNOWN并提出最小决策点，不擅自换引擎。
- Codex可在已授权范围内自主决定具体实现、必要迁移、APP/Web接线和定向验证；不逐动作请示。
- 对每条AC至少验证普通入口到真实API/持久化的实际路径；受控Widget/单元测试作为补充并明确标识。重点覆盖输入合法性、未知/缺失输入、计算失败、历史重读、重算和权限边界。
- 只对改动代码做分析与定向测试；有真实APP链时做最短必要双模拟器验证。无需重跑v10.1.9全部六项、旧通话、完整硬件矩阵或无关全库静态检查。
