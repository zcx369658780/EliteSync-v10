# v10.1.12计划：集中UI、信息结构与文案完善

日期：2026-11-14（北京时间）。状态：TASK_ISSUED。依据：Owner授权v10.1.12决定及路线图V2.0。

## 1. 目标定位

业务功能与真实后端优先阶段已经推进到v10.1.11。本版集中收口体验层：导航职责、信息架构、共享组件、字体/颜色/密度/主题、页面文案、键盘/返回和可访问性。

不是重新设计一个新产品，也不是推翻既有视觉资产。应先理解当前候选真实页面和用户路径，再确定统一规则。优先改善清晰度、一致性、可读性和操作确定性；装饰性动画和纯视觉特效不是目标。

## 2. 用户体验原则

- **清楚优先**：页面标题、当前对象、状态、下一步动作明确；避免内部术语、调试词、重复说明和模糊按钮。
- **一致但不僵化**：共用控件有统一行为；复杂工具可保留适合自身任务的专用布局。
- **状态真实**：加载、空、成功、拒绝、错误、离线、权限失效和结果未知各有准确反馈；不得假成功。
- **输入可靠**：切页/返回/键盘弹出时不意外丢失合法输入；提交结果未知时保留原命令与重试语义。
- **权限可理解**：分享范围、关系前置、媒体/消息权限、危险操作和不可用原因用普通语言解释，不削弱服务端门禁。
- **可访问**：支持大字、系统文字缩放、键盘/焦点、语义标签、可读对比度与足够触控尺寸。
- **克制**：不增加大型业务、复杂动效、无必要页面和重复导航；不因UI版本改变产品定位。

## 3. 五阶段实施

### 阶段A：我的 / 设置
盘点并统一个人资料、资料展示、隐私、账号安全、密码、帮助反馈、主题偏好、通知偏好和特色工具入口。区分账号级设置与本机偏好。危险操作与不可逆动作使用明确说明和二次确认；保存后状态与回执一致。完成后作为共享控件与文案规则的首个代表区。

### 阶段B：消息 / 聊天
统一会话列表与聊天页的标题/返回、消息密度、发送者/时间层级、附件卡片、上传/发送进度、失败重试、空态和权限失效。离线只读和在线写入状态清楚区分。保留正式构建与restorationLocalBuild差异，不互相代证。

### 阶段C：首页 / 进展
明确首页作为发现/入口的职责，进展作为本人参与、匹配与连接状态的职责。减少重复卡片和不清楚的入口；状态摘要提供下一步操作。不得把Discover兼容路由变成额外底栏分支。

### 阶段D：匹配 / 社交 / 特色工具
统一匹配、好友、搭子、社区、正式关系和特色工具的页面框架与状态表达。普通用户信息优先，高级参数/算法解释按需展开；玄学解释明确来源和限制，不伪装权威判断。保持不同关系类型、许可和状态的独立语义。

### 阶段E：必要Web管理页面
按桌面端场景统一导航、标题、表格/详情、筛选、状态徽标、表单和反馈语言。仅覆盖本版实际涉及的必要管理页面，不做全后台大迁移。

## 4. 设计系统交付

Codex先盘点当前主题与组件，优先扩展已有体系；确有重复或不一致再抽象。形成简洁可执行的Token/组件约定，至少涵盖：
- 色彩角色与明暗主题；
- 字体家族、字号层级、字重、行高；
- 页面边距、区块间距、卡片密度；
- 按钮层级、输入状态、卡片、列表、导航、弹窗/底部面板；
- 加载/空/错误/拒绝/成功/离线/权限失效/结果未知；
- 焦点、语义标签、文字缩放和触控尺寸。

避免一次创建庞大组件库；以真实重复场景为抽象依据。

## 5. 验收与证据

- 对四个底栏分支及关键非底栏入口做导航走查。
- 每阶段至少选择代表性关键旅程，覆盖正常操作及至少一种有意义的非成功状态。
- 核对大字/系统文字缩放、键盘遮挡、返回、焦点与语义信息。
- 对APP/后端业务链仅验证受UI改动影响的关键点，状态以服务端事实为准。
- 必要Web页面在桌面视口检查可读性和表单反馈。
- 记录截图时绑定候选版本、设备、路径和状态；不复用旧候选截图冒充新证据。
- 不重跑全部旧AC、全设备矩阵或全历史截图。

## 6. 明确不做

- 不新增业务表、API合同或大规模后端重构。
- 不改匹配排序、资格、关系状态机、隐私授权、消息/媒体/RTC协议。
- 不接新供应商、付费SDK、分析/广告服务。
- 不开发相识后破冰、约见、共同计划、纪念日。
- 不把MBTI、星盘、八字或紫微包装为诊断、科学确定性或权威匹配。
- 不隐藏未完成状态或以演示内容填充空态。
- 不操作手机，不使用真实用户/生产数据，不合main、不发布。

## 7. 成功定义

一个用户能从启动进入四个主入口，清楚找到本人设置、反馈、消息、匹配/进展和特色工具；跨页面返回与输入状态可预测；重要状态和权限解释准确；同类组件行为一致；大字与键盘场景仍可操作；必要Web管理页面清晰。该定义以代表性旅程和证据判断，不以页面全部重写或视觉主观喜好判断。
