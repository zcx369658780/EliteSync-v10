## 4. 管理员恢复与轻量备份

在任何写入前：
1. 只读核验现有管理员账号、角色、权限、认证来源、相关表结构、后台登录方式和必要配置。
2. 导出最小必要的管理员/角色/权限关联记录及本版将触及的配置，记录来源、时间、行数、文件清单和SHA-256；存入本地受控目录或已有安全备份位置，不进入Git。
3. 若旧账号可安全恢复，恢复最小必要权限；若账号/密码确已丢失或来源不可信，停止无效追溯，创建新的专用开发管理员。
4. 使用正常密码哈希/重置机制，不将明文密码写入数据库、命令历史、日志或报告。
5. 通过真实后台登录/退出、普通用户拒绝、管理员允许、后端API授权及会话失效验证。
6. 新凭据通过受控本地方式交付Owner；报告仅记录账号标识、角色、恢复/创建方式与凭据交付通道，不记录密码/token。
7. 不因管理员权限扩大用户私密资料访问权，不绕过既有权限与独立同意。

本版需要改变现有数据库时，先备份目标数据库及迁移状态并验证归档可读。备份不必做成复杂的新系统，但必须知道来源、内容和恢复方法。不得将历史真实用户全库、聊天正文、出生资料或私人媒体导入开发试点。

## 5. 冻结验收标准

### AC-10.1-01 云端身份与隔离
服务器、代码Commit、部署目录、环境、服务、端口、数据库与持久存储身份明确；未覆盖未知或既有生产资源；回滚点可识别。

### AC-10.1-02 备份与管理员
管理员/角色/必要配置完成轻量备份且归档可读。旧账号能安全恢复则恢复，否则创建专用开发管理员。后台登录、退出、管理员允许、普通用户拒绝均有真实证据；凭据不入Git或报告。

### AC-10.1-03 APP/API
构建独立v10.1.0测试APK或使用经核实的受控客户端，明确连接实际云端API。验证登录、退出、会话、资料读写；不得用localhost、mock或旧生产API冒充云端成功。

### AC-10.1-04 匹配与关系
用虚构账号验证匹配生成/读取、Connection与Messaging Consent。Match不自动建立Connection或Messaging Consent；遵守Owner已批准的D1–D6与现有授权合同。

### AC-10.1-05 对话与媒体
验证虚构账号的文字消息、历史读取、消息状态及必要图片/短视频上传、播放与撤权拒绝。未验证的媒体类型逐项NOT_RUN。

### AC-10.1-06 星盘与算法
验证本命、八字、紫微以及v10.0.11已接受的双人盘、行运、太阳/月亮回归通过实际云端服务执行。使用虚构输入，复用已准入的本地计算引擎和依赖；不重开发算法、不使用未准入云端引擎、不夸大精度。

### AC-10.1-07 视频与实时服务
用受控双方客户端验证实际信令和双向媒体、挂断及必要失败/重连场景。记录SFU/RTC身份、鉴权和网络路径。只有JWT/WebSocket/call记录不算视频通过。若需要新增公网/安全组/防火墙规则，停止该项并向Owner报告，不越权修改。

### AC-10.1-08 管理后台
受邀同事能按受控访问方式登录后台并查看被授权的开发数据；普通账号不能访问管理路由。禁用、退出、权限变更后旧会话按现有安全合同失效。

### AC-10.1-09 持久化与重启
对本版必要的Laravel、数据库、队列/缓存及相关实时服务执行受控重启；APP和后台重新登录，读取此前虚构测试结果。证据关联实际Commit、数据库身份和运行时间。

### AC-10.1-10 集中交付
唯一报告 docs/versions/v10.1.0/IMPLEMENTATION_REPORT.md 包含精确代码/部署身份、备份与管理员处理结果、测试矩阵、关键原始证据索引、回滚点、失败/NOT_RUN和非作者复核。Codex不得自行宣布Astra接受或生产就绪。
