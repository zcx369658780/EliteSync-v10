# B3 目标信息架构 V1

以固定任务 `8117980c8f2b2e8ada61db52450a9aca7b643e13` 为依据，编码前设计。实施差异与运行验证另见最终实施报告。

## 四个入口

| 入口 | 本人目标 | 权威来源与动作 |
|---|---|---|
| Home | 理解当前状态和下一步 | GET `/user-state`。只映射既有 `next_actions.code`，按服务端顺序突出一个主动作。无结果、过期或失败明确展示，恢复须重新读取。有限的 Buddy、好友社区、活动入口继续独立可达。 |
| Progress | 理解本人关系旅程并作出决定 | B2 聚合准备、偏好、参与、自动化、轮次和提案摘要。既有 `/journey` 取得合法提案上下文。既有 `/connections/{peer}`、会话列表和正式关系 API 分别取得各域状态。每个域独立标注来源与动作，未取得的状态保持未知。 |
| Messages | 进入当前有权访问的沟通 | 保留现有会话列表和进入前复核。增加独立站内通知入口，聊天和通知保持独立列表、计数和已读处理。 |
| Me | 维护本人资料、偏好、隐私和可选工具 | 按目的紧凑分组，直达已有编辑器。私密资料与展示资料分开，匹配输入与 Lifestyle 分开，隐私及账户安全明确可达。可选 MBTI、星盘和八字保留自愿使用。 |

## 规范入口与兼容

- `/user-state` 是状态与自动化的唯一控制页。Home、Progress 和必要上下文只链接同一页面。完整旅程呈现在 Progress，自动化页聚焦授权、期限和执行结果。
- `/progress/match` 保留慢约详细操作页。Progress 将当前提案和本人需要处理的事项提前呈现，详细解释和历史仍可查看。
- `/progress/connection` 和已授权 peer 详情保留现有 CN、MC 操作。Progress 可根据当前服务端上下文直达已有合法会话，打开时继续复核，不以摘要授予权限。
- `/me/private-identity`、`/me/showcase` 保留路径，减少说明页中转，直接使用原编辑页。用途及发布说明在编辑上下文保留。
- Lifestyle 完成后的修改沿用原自动保存、revision、重试和动画，只增加快速返回已保存摘要的低风险导航。
- 既有 `/match`、`/profile` 别名及通知、typed chat、工具深链继续兼容。`/buddy` 的既有拒绝合同保留，独立 Buddy 规范入口为 `/buddy-v1013`。
- Home 保留 Buddy 和社区有限入口，Progress 不再复制这些体验。Me 的动态维护保留同一社区页面的上下文入口。

## 数据生命周期

复用 SessionBoundPage、RelationshipApi 和既有账号/authority epoch 合同。切号、后台和重新进入页面时不得展示前账号或未经重新读取的旧事实。读取失败清除相应当前投影，界面提供重试，未知不能替代为“无关系”或“已完成”。

B2 `/user-state` 为只读聚合。`/journey` 与 `/formal-relationships` 沿原合同可能协调期限与当前业务事实，须在报告中明确记录这些语义。客户端不另算资格、到期、匹配排序或关系事实。无需新增业务表或更改状态机。

## 权限与视觉

保留隐私分享、匹配决定、Connection、Messaging Consent、正式关系和退出删除的明确行动。普通查看、返回和自动保存直接执行。OS 权限继续按用途触发，复用现有私有媒体管线与账号隔离存储。

复用既定主题、低刺激色块、构成与现有 B1 美术。本设计使用现有资产。B4、阶段 C、Owner 手机、真实运营与 main 集成均在本版边界之外。

九项代表旅程按 [操作成本基线](B3_OPERATION_COST_BASELINE.md) 同逻辑状态后测。至少六项减少一个无必要跳转、重复输入或确认，至少四项总操作减少 20%。
