## 产品边界

- 默认保留首页/进展/消息/我的四个底部入口，不新增第五入口。
- Home使用B2 /api/v1/user-state及next_actions，不创建竞争状态真相。
- Progress清楚展示关系旅程，但Match、Connection、Messaging Consent、Conversation、Relationship保持独立。
- Buddy独立于恋爱匹配；社区保持有限相互了解场景，不做无限Feed。
- B2状态中心和自动化设置只有一个规范入口。
- Messages保留ConversationAccessGate、消息同意、block、隐私、私有缓存、媒体授权和账号切换保护。
- Me集中个人资料、偏好、隐私分享、账号安全和可选工具。
- 普通导航、查看、草稿保存等低风险操作不增加无意义确认；隐私分享、匹配接受、消息同意、Connection、正式关系、删除/退出等保留明确行动。
- 不自动接受匹配、不自动分享、不自动发消息、不确立关系。
- 视觉方向冻结：低分辨率质感、色块、几何构成、低刺激配色、二次元/构成主义；本版不重新开启美术方向会议，不为装饰生成新素材。
- Android权限按用途触发。
- 不做B4运行时AI，不接阶段C身份/征信/芝麻信用/蚂蚁积分/Push/支付。
- 不改匹配算法、候选排序、资格权威服务和关系状态机。
- 不使用真实用户/生产数据，不操作Owner手机；整体实机验收在B1+B2+B3完成后。
- 不合main、不正式发布、不开展真实内测/运营。
