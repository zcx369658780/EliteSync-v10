## 实现与字段边界

| 字段或资源 | 本人编辑与提交 | 对外读取与撤回 |

| 介绍、兴趣、生活线索、开场话题 | 本人重新填写或选择，编辑后产生新内容版本 | 旧发布与新草稿分离，批准后由本人明确替换 |
| 0至6张展示照片 | 私有存储、归属校验、解码重编码，保存排序与移除 | 当前发布版本、照片成员及关系范围逐次校验，旧 generic 媒体入口拒绝该 disk |
| friends / contacts / relationship 受众 | 本人明确选择，随内容版本审核 | 当前好友、有效匹配/获准联系或正式关系分享规则分别核验；拉黑及账号状态参与判断 |
| 头像与本人基础资料 | 保留既有独立编辑入口，图片归一化处理复用 | 现行头像权限服务继续处理，Showcase相册由本人单独选择 |
| 运营参与申请 | 普通 APP 提交说明，服务器持久保存并返回反馈 | 正常 Web 账号页面处理；当前实人状态仍为未核验，匹配资格还受问卷等现行条件约束 |

生日、精确出生时地、问卷原答、深层履历等保留原有用途。提交快照不可变，审核绑定具体内容版本，图片引用只暴露本用途的鉴权地址。撤回和移除约束后续服务端读取。已发布快照在替换或撤回前保留其选定受众，已另存的内容超出服务端撤回范围。

版本和幂等处理覆盖保存、提交、上传及发布撤回。照片上传重试保留同一 UUID，客户端隔离会话变化及迟到结果，私有图片在前后台与权限变化时重新读取。旧 approved 草稿可进入新提交审核，受限账号保留本人历史只读。
