## 4. 分项回归和专项

- **资料。** 展示草稿一次注入 503 后保留输入，重试成功。同号冷启读回展示昵称与城市。独立 HTTP 和 MariaDB 两字段一致。实际 Android 只改昵称时保留城市，随后显式清除城市并读回 null。对端账号草稿保持原值。基础资料和头像的完整修改仍待验证。
- **社区。** 同候选实测详情喜欢和取消、评论、独立回复及加载下一页。对具名长列表在进入详情和点赞后返回，同一作品顶部从 y=210 移到 y=284，超出原采集容差 10px。页面保留 `PageStorageKey`，详情返回会重新加载，当前证据不足以区分列表布局、重读数据与滚动恢复的贡献。主夹具测试账号未通过既有合成媒体许可，`POST /media` 返回 404。主库完成文字发布、受众收窄及撤下。同一 APK 在具名合法媒体环境完成合成图片发布、收窄到自己及撤下。独立 HTTP 证实收窄后好友读 404，撤下写入 200，双方再读 404。
- **消息与关系。** 两台分别提交候选接受，HTTP 两方状态为 `MUTUALLY_ACCEPTED`。未建立联系或聊天许可前，两方聊天写入关闭。在独立合法关系中，从客户端申请联系，再经独立 HTTP 对端接受；联系单独成立仍不可发消息。完成两方聊天许可才出现文字权限。1011818 会话中文本发送成功，附件按钮在仅文字环境保持禁用。附件正向环境的独立 MariaDB 一条消息、一个附件关联、同编号回放、异载荷 409、丢回执与对端字节一致具名通过，最终候选也实拍对端读图。客户端实测 422 后取消并恢复文字；另一次合法图片提交发生丢回执，服务端同编号只有一条消息，图片在聊天里可见。点击原编号重试后仍提示未完成，冷启后残留待确认状态，根因 UNKNOWN。撤权后独立读图与历史均为 404，Android 清空历史和图像；换到另一合成环境的账号未见原会话。发布候选资料 v2 后，既有候选仍绑定 v1。
- **通知。** 独立 HTTP 同时核对仍有权限的目标，以及收窄、Block、撤下、缺失。失效记录回落历史，正文、载荷和路由为空；无权读取返回 404。Android 实测通用提醒进入当前仍有权限的评论并可返回通知中心；历史项仅显示「通知已不可用」。其他通知类型与历史附件跨权限组合仍待测。
- **Buddy、设置和退出。** Buddy 已在 App 发现具名线上学习活动、申请、回到我的搭子并撤回。创建、双边接受/拒绝和取消仍待补。个人中心、隐私和设置可达，静默提醒的开关和独立 HTTP 持久值一致，重入读回并恢复原值；设备实操和 Block 等安全流程仍待补。确认退出、重登本人 v2、切号后无本人 v2 已实测。D4-A 的真实对象请求渠道继续不可用。
