## 2. P0｜文案矩阵证据分类修订

这是本轮首先处理的事项。

现有 `UI_S4_COPY_FINAL_AUDIT.csv` 已完整登记1230条，但顾问独立审阅发现：

- 501条 `VISIBLE_VERIFIED` 中，500条使用 `content-desc`。
- 35条 `REPLACED` 全部使用 `content-desc`。
- 20条 `SYSTEM_CONTROL` 中，19条使用 `content-desc`。
- 4条 `COPY_REWRITE_CANDIDATE` 也使用 `content-desc`。
- 670条 `NOT_RUN` 保留。

Android `content-desc` 是无障碍语义标签，不必然等于屏幕上实际显示的文字。

特别是原438条 `UNVERIFIED` 中，152条被转为 `VISIBLE_VERIFIED`，但其证据字段均为 `content-desc`。

### 要求

1. 保留原始1230条编号及全部历史字段。
2. 优先重新核验原UNVERIFIED转为VISIBLE_VERIFIED的152条。
3. 核验35条REPLACED是否确实存在对应的屏幕可见替代文字。
4. 对500条content-desc证据逐条检查是否另有截图、实际文本节点或其他可确认的屏幕可见证据。
5. SYSTEM_CONTROL 应有平台控件身份依据，不能仅凭语义标签推断。
6. 对仅有语义标签而无法证明屏幕可见的项目，不得继续冒充可见文案通过。
7. 保留原任务规定的最终处置枚举；必要时增加证据类型字段，不擅自创造新的处置状态。
8. 不要求盲目重写全部文案。
