## 如何读计量

- C 为设备实际点击，包括输入焦点、按钮、选项和系统照片选择。S 为实际滑动。I 为独立字段输入或编辑动作，分列录入字符数；问卷选项按 C 统计。选择精度、独立算法性别、图片及受众等互相独立的控件可计 I，同时保留产生的实际点击。C、S、I 各自报告，含重叠动作的 I 不再与 C 相加。
- N 为观测到的页面、弹窗、频道或向导步骤变化，展开同页内容单列为点击。Android 系统返回或收起键盘记 B。截图之间发生的同页数据刷新不计 N。原始事件保留试探性动作，可对照步骤编号复算。
- W 为明确等待动作到首次可见验证之间的采样量，含约 2 秒的 UI 层级探针延迟。未采样保留空白，审计脚本目标错误引起的超时保留在私有日志，不进 W。W 不含阅读、判断或键盘逐字时间。服务端耗时另以回环代理记录为准。注册 201 约 0.30 秒，首次三盘正式 POST 约 1.48 秒、随后 GET 约 0.17 秒。
- 截图索引与同次无障碍树映射。用户填写内容、账号值、合成正文和个人盘数值在远端索引中去除。字数列分别记汉字数和去除空白后的可见字符数。清单以采样页可见控件和无障碍说明为限，按页和原文去重；个人填写、定位、合成用户正文及个性化数值在私有原图留证。题目与选项文案可以保留，测量不披露选择的答案。说明量按已采集页面比较，无障碍风险为观察结果。

## 首次、日常和恢复成本

- **首次打开至抵达首页**，QA-A 合计 20 / 0 / 3 / 16（C / S / I / N），含五场景与一次回改、五页引导、一次键盘返回。8 次等待采样合计 20.90 秒。仅注册加引导的 U01 为 11 / 0 / 3 / 8。必要问卷在 QA-B 另测 24 / 0 / 0 / 25，其中 20C 是作答，不能把两个账号拼成一个首次流程。
- **点击最多**的汇总任务为 U02 的 37C，含两个账号、回改和中断恢复；在独立的首次任务中，必要问卷为 24C。U05 浏览、更正及找入口共 27S，为本轮滑动最多。
- **日常路径**，从我的重入已保存三盘为 2 / 1 / 0 / 2；从首页精选改看好友详情 2 / 0 / 0 / 2，回复并回原详情 4 / 0 / 1 / 2，发布列表点喜欢及取消 2 / 8 / 0 / 1。发文字 4 / 0 / 1 / 2，从对话检查通知并回消息列表 2 / 1 / 0 / 5。主动退出 4 / 7 / 0 / 4，同账号重登 4 / 0 / 2 / 1。各行有自己的起点，包含实际探索步。
- **失败和恢复**，单项坐标拒绝 1C，正式补齐路径见 U04。展示草稿失败样本 6 / 4 / 2 / 3。第一张图片的失败反馈后，合成夹具按现有门禁补齐，重新选择到已完成 3 / 4 / 0 / 3；其中 4S 是选择器未关闭后的查找。聊天附件失败至刷新为 3 / 0 / 1 / 2，未找出恢复正常发送的可用路径。Lifestyle 第二题中断重入只需 1B + 1C。
- **导航最多**的是 U02 汇总 38N，其中必要问卷 25N 包含题间推进；任务汇总的 N 表示变化次数。较深的持久页面路径见我的→星盘画像→三盘本命→历史详情（U05/H），以及好友频道→作品详情→评论面板→回复编辑（U06/A，回复为面板内状态）。工具概览和继承的编辑状态须在设计时区分。
- **重复输入**集中在城市。私密资料、展示草稿和匹配输入均出现城市；QA-A 输入私密城市后，展示复用处显示依据不足，匹配端提示仍需明确填写。QA-B 的匹配表单有一次城市内容重输。昵称另在私密资料和展示表单尝试输入。三盘共享正式输入，已观察的 1 次正式确认同时提交三盘。
- **说明量**按单次截图无障碍树中去重后至少 14 个汉字的说明行计。星盘画像约 204 字（U04-02-astro，也见 U12B-03-peer-tool），展示资料约 141 字（U03B-01-fields），首题问卷约 136 字（U02Q-01-question，含业务题目和选项）。这是采样说明体量，容器可能合并滚动范围，需结合截图判断当前视口。文案矩阵共 1230 条，按任务页和原文去重。
- **确认与折返**，注册与重登分别勾选一次当前协议；退出、候选回应、三盘正式提交与修改、作品受众收窄、Buddy 申请及撤回各有明确确认。连接和消息许可各保留对方接受。U07 默认好友发布实际从按钮直接提交，U10 提交后的确认只关闭反馈；后者可简化。矩阵另列系统返回，包含收键盘和安全退出范围中的界面返回，分段行与汇总行有重叠。
