# 2026-11-26｜V2 百度手动地点检索

## 本轮实现

- 输入、拼音选字和取消时均为零请求。点击搜索后优先使用离线候选，离线未命中且明确同意时，鉴权后的 POST 至多发起一次百度地点检索 3.0。既有限流继续执行。调用失败时返回相应状态，用户可再次明确发起搜索。 [百度地点检索 3.0](https://lbsyun.baidu.com/docs/webapi?title=placev3%2Fguide%2Fwebservice-placeapiV3%2FinterfaceDocumentV3)
- 服务端签名请求只发送地点名和城市以及接口参数。百度提供地点匹配，WGS84 由独立目录提供。如果只有区县或城市级候选，界面标注约略位置，选中后再确认。草稿地点使用行政区代表点标签。命盘仍由 Owner 核对并提交。
- 基于 GeoNames CN 快照生成 348 个城市、2815 个区县代表点。隔离预检发现旧生成规则可能将广州别名选作规范名称，修订为按行政层级识别完整名称。规范目录 SHA-256 为 `17ca7e648a7c80fcf398cf40e09e66600d6c828f80913b00e91a44f6dbd5e510`。原数据及验证产物留在本机评估目录。 [GeoNames 数据说明](https://www.geonames.org/about.html)
