# EliteSync V2｜共享 Staging 合成私信授权决策

2026-11-22（中国标准时间）。本地候选已在隔离 MariaDB 验证。云端合成 Connection、MC 和 WSS 的启用均待单独批准。

## 作用域和威胁

本地 CLI `qa:staging-connection-pair` 以本机受控 JSON 记录单一实例、MariaDB schema、实际 server_id、HTTPS origin、合成批次、A/B 主体、工单和 UTC 截止时间。候选要求 staging 环境、显式开关、实际 10.11 MariaDB 连接和独立实例标记吻合，同时限定双方为 active 的合成测试普通用户。失配、撤销或到期时拒绝，重放同一对也会被拒，原审计行保留。配置中的标记摘要与数据库内标记分别配置，复制测试库时不得复用标记和运行绑定。现行候选硬绑定独立本地实验身份，目标指向现有云端时不能授予。

主要威胁包括把普通用户、管理员或其它批次伪装成合成账号，把清单重用于另一个实例或 A/B 对，利用旧会话跨 Connection 或消息同意代际获得访问。CLI 只有实例运维主体可运行，线上没有写授权清单的接口。允许的 A/B 对仍须通过 Connection 生命周期、双方消息同意、Block、令牌有效性和当前房间代际。授权回收保留工单及时间，PHP 只读、创建、发送及 WSS 调用仍走现有服务端合同。 [APP-T07 接受回执](../../../architecture/ELITESYNC_V10_APP_T07_CONVERSATION_AVAILABILITY_MESSAGING_CONSENT_FOUNDATION_ACCEPTANCE_V0_1.md)

## 待 Owner 决定

如需进行下一次云端演练，请单独指定两名合成普通用户、批次、目标实例、数据库标记、最迟失效时间和撤销责任人，同时审批独立配对授权、迁移及 WSS 正向测试。云端审批清单建议沿用既有 Owner Ed25519 签名和私有操作回执，并绑定目标及有效窗口。当前可继续审阅本地候选和下列验收场景。

| 场景 | 下一轮验收标准 |
| --- | --- |
| 拒绝和正向握手 | 无效或过期 bearer 返回 401，具名能力不足返回 403，对无 Connection、无双方 MC 或不可识别的私有对象返回不披露关系的 404。确认双方授权后真实 TLS Upgrade 返回 101，且只收当前代事件。 |
| 撤权和旧令牌 | 双向分别执行 Block、撤销 MC、撤销合成授权或注销设备会话。确认关闭当前 WS、丢弃未授权帧，原令牌的重连被拒。单独记录每个触发点的退出码、握手状态和关闭时序。 |
| 第二代重连 | 复建具名 Connection 与双方 MC，按新代核对新令牌和正向事件。旧房间、旧附件、历史正文和旧令牌均须保持隔离。 |
| 证据区分 | 双实体、真实 WLAN 四窗口和模拟器路径分别记账。底层连接或上游 502 独立判定为传输失败。 |

云端 `STAGING_WS_ENABLED` 与 `MATCHING_FOUNDATION_WEBSOCKET_ENABLED` 保持关闭。真实管理员和普通用户均不进入合成授权。R1 为 PARTIAL，封闭内测及生产为 NO_GO。
