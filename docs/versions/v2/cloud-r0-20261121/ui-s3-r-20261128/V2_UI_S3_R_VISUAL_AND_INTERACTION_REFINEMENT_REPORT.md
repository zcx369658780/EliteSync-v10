## 功能与测试读回

- **聊天回执。** 客户端收到 `client_message_id_payload_mismatch` 后保留原尝试并显示待核对。当前代授权的独立读取必须匹配发送者、接收者、原编号、正文、回复身份及有序媒体身份。同号异载荷既不会被标成成功，也不会进入终态附件取消。普通 422 的取消和文字恢复保留。PHP 8.4.28 与隔离 MariaDB 实测提交成功后丢回复、同载荷回放、异载荷 409、同一消息及媒体关联各一条和对端文件逐字节一致。1011817 另完成实际选图、丢失响应后按原号只读核对且无重复 POST、冷启动读回、422 取消后继续发送文字。撤回聊天许可后，历史与图片 HTTP 404，设备刷新不再显示图片。
- **展示草稿。** 同包在合成 503 后保留输入，按「重试保存私有草稿」得到 v6，昵称和城市在冷启动、独立 HTTP 及 MariaDB 回读一致。独立完整 PUT 验证单字段编辑保留城市、显式清除及对端草稿隔离，既有候选留 v1。
- **匹配和权限。** 通过独立草稿、具名合成运营审核、发布及轮次建立 v1 候选。两台模拟器分别提交决定，POST 均为 200，两侧独立读取为 `MUTUALLY_ACCEPTED`。发布新版后旧绑定保持 v1。建立联系后仍须单独激活聊天许可。候选界面核对快照主体，回复前的候选样本未显示身份证号、出生日期或 WGS84。
- **排盘和普通注册。** 后端生成后当前命盘 v2 输入／结果一致，实际 Android 三盘与独立授权 HTTP 对齐。历史 v1 的跨账号详情返回 404，精度状态保留。未核实协议的普通注册返回 403、无令牌、MariaDB 无用户写入。
- **测试。** Flutter 定向套件 156 通过，其中含附件冲突、权限变化、八字／紫微解析、西洋盘面标签避让、隐私和 Buddy。静态分析 0 error、0 warning、15 info。PHPUnit 12.5.42 的注册和消息两组在 PHP 8.4.28 隔离 SQLite 上共 13 测试、127 断言通过。第一次 PHP 运行受缓存和权限保护停止，后以无网络独立测试容器完成。扩大测试曾有旧工具历史的 422 和 503 夹具失败，尚未取得同基线结论。
- **计量。** C、S、I、N、W、B 多项由 Android 操作日志记录。W 含观测探针时间，三盘本轮撮录等待另计。退出为 3C / 0S，确认保留。旧 4C 含定向定位动作，留给 UI-S4 以同起点、权限及端点复测。 [操作成本冒烟](UI_S3_R_INTERACTION_SMOKE_MATRIX.csv)

- **性能冒烟。** 同一模拟器、同一账号、同一 v2 数据，各跑一次冷启和首页至三盘。Android 启动耗时 2,467 ms → 2,404 ms，完成路线后 PSS 354,223 KiB → 377,918 KiB。宿主各取得 10 帧，无法据此判断 Flutter 帧耗或内存回归。长列表、素材冷热及页面重建没有统一性能证据。
