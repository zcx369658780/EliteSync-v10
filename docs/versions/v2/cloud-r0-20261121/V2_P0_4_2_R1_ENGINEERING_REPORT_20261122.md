## R1 源码差异与边界

- 私信快照携带当前响应的 room_key。已知当前代际时，拒绝代际不符的快照。缓存读取资格仍来自该登录进程内既有的对象授权和可信时间。
- 待确认发送记录绑定其原 room_key。明确发现新代际后，旧待确认发送的引用和附件选择不会恢复到该会话，普通本地文字草稿维持既有语义。
- 已知撤权或代际替换时，撤回旧快照和已解码预览的本次展示资格，并通知会话列表、搜索、通知及已打开的音视频控件重新校验或释放。列表快照也保留每个对象的 room_key。
- 最新窗口和列表请求记录联网重验轮次。恢复或切换账号后，较早轮次的迟到响应不能写回旧快照。新增两项具名测试覆盖离线期间远端换代、旧正文/回复/缩略图/预览清理与后台刷新迟到。判定仍受 Widget 执行阻断。

## 离线行为及 Owner 决策

| 状态 | 当前处理 |
|---|---|
| 在线 | 当前对象授权后展示和保存，明示拒绝或 room_key 改变触发撤权与重验。搜索和通知不提供离线历史授权。 |
| 持续离线 | 同一已开启登录进程仍可按既有规则只读此前获准缓存。设备无法得知离线期间发生的远端撤权，实际窗口最长受既有 30 天保留、登录和本地环境规则约束。 |
| 离线冷启动 | 进程级可信时钟与读授权不会从密文重建，禁止借缓存恢复私信权限。 |
| 离线前后台切换 | 后台隐藏私密状态并中断旧响应。回前台开启新一轮当前授权核验。无网络时，既有规则本就不复用进入后台前的授权。 |
| 恢复联网 | 当前读建立新上下文，已知旧代快照、旧引用和旧预览失效。跨轮次迟到响应不能重新建立授权。 |

**OWNER_DECISION_REQUIRED。** 设备完全离线时无法即时获知远端撤权，现有长期保留上限也不能直接视为独立历史读授权。R1 保留原有已开启进程的有条件只读体验，等待 Owner 选择。

| 选项 | 隐私与撤权 | 离线可用性 | 工程实现 |
|---|---|---|---|
| A · 在线重新授权后才可展示私信历史 | 对失联期间的撤权最保守。没有可确认的当前授权即隐藏正文、预览和附件。密文保留照既有规则。 | 完全离线时不能看过去私信。 | 限制聊天、列表、媒体统一依赖在线当前读，补断网切换测试。 |
| B · 保留有期限的独立本地读权限 | 可约束暴露窗口。离线期间仍无法即时感知远端撤权，联网收到撤权即停。Owner 需定时长、对象类别和容忍范围。 | 允许条件内只读，附件可另定短期限或要求在线。 | 设计绑定账号、设备、登录、代际与对象范围的有期限凭据，可信计时、到期与重联失效；与 30 天密文保留分别管理。 |
