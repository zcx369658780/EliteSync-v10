# 慢约会（EliteSync V2）操作手册

**登记准备稿 · P0.3 实机修订 · Android 功能测试版 10.1.18-v2-function-p0 / 1011805 · 2026-11-21**

## 1. 软件概述

慢约会由 Android 应用、服务接口和独立 Web 管理后台组成。用户可通过应用管理个人资料、使用独立本命工具、参加符合条件的慢约旅程，或使用好友社区及 Buddy。管理人员在独立后台查看账号、处理形象审核和举报，并可查看操作审计。

测试包名为 `com.elitesync.v2functionp0`，适用于 arm64 Android。本准备稿采用独立开发包与合成服务环境，活动示范使用虚构资料。Android 源码对应提交 `36ae37206f482109e0bfc7a0f95335fc056da323`。本次真机截图来自同一 APK，运行设备为 Android 16。 [P0.3 实机报告](V2_FUNCTION_P0_3_ANDROID_1011805_SINGLE_DEVICE_REPORT_20261121.md)

## 2. 账户、资料与独立本命工具

已有账号可在登录页输入手机号和密码，阅读并勾选协议后点「进入慢约会」。新账号入口为「还没有账号，去注册」。切换账号时，从「我的」打开「设置」，滑到「退出账号」，确认退出后再登录另一个账号。进入首页后核对当前账号，在「我的」重开私有页面核对资料。P0.3 实测使用已有的合成账号。

在「我的」选择「私密资料」。修改昵称后点「保存昵称」，核对页面的服务端读回确认。城市可单独保存。形象草稿可独立编辑并提交审核，审核通过后由本人确认是否发布。本人可管理发布受众与分享范围。

依次打开「我的」「三盘本命」「三盘本命 · 手填与排盘」。输入出生日期和时区，按实际情况选择未知时刻或精确到分并填写当地时间。点「保存、计算并持久重读」，核对输入版本、结果版本和计算状态。显示为 `COMPUTED_UNVERIFIED` 的结果供参考，部分模块会显示未知。出现运算暂不可用或保存结果未确认时，先重读当前记录、核对原输入和版本，再决定是否继续修改。

## 3. 慢约、候选与正式关系

从底栏打开「匹配」，或点首页「查看匹配」。按页面补充匹配资料、问卷和生活方式探索，再到报名入口确认参与意向。看到资格不满足时，可按提示检查准备项目。P0.3 的候选旅程从已公布的合成轮次开始。

候选发布后，在「匹配」查看结果，选择回应并在弹窗确认。双方选择会分别记录。点「匹配记录」查看本人历史，历史中的对方资料需通过当前资格及受众检查。

接收方在「设置」「好友与请求」打开「接收新请求」。符合条件的当前好友或连接可在「匹配」打开「正式恋爱关系」，输入对方用户编号并确认发起。双方分别选择「本人确认正式关系」并确认弹窗。服务端同时核对双方当前有效的身份凭据。暂停后，重新激活仍需双方确认。任一方可以结束关系。图 A08 为标注 TEST_ONLY 的合成演练，实际双确认后的界面用语是「已参与」。

## 4. Connection、消息同意与私信

从「匹配」点「连接与消息许可」进入「连接与消息同意」。核对对象后发起连接，由对方按「接受连接」。双方再分别申请和接受消息同意，才可点「进入消息」。在对话中输入文字并发送。接收方可在「消息」打开同一对话。Block 后，旧对话显示无法读取，消息列表重验后隐藏该会话。P0.3 的 Block 由本机隔离接口施加，实测的对话页未找到可用的拉黑控件。

本地测试包覆盖文本收发。操作期间遇到请求结果未确认，先刷新读取服务器当前状态；确认未处理时再按页面提供的同键流程继续。系统推送、联系人导入和音视频需各自具备合格服务与授权。

## 5. 好友社区、图片、Buddy 与通知

在首页点「发布和管理我的作品」，填写标题及正文，核对受众后点「发布状态」。默认面向双向好友，也可选择「仅自己」。图 A10 记录文字发布成功。图片流程需从「选择图片」进入系统图库，等待上传后再发布。图片、头像、评论和历史媒体受众的真机验收另待采集。

在「我的」修改头像时确认使用合成图片，上传后重新进入检查当前版本。遇到旧头像修订冲突，刷新后再提交，避免覆盖已保存的新版本。

从首页点「吃饭 / 学习搭子」，开启「接收搭子请求」。在「我的搭子」选择类别，填入主题、地点类型和时间，保存仅本人可见的草稿。随后开放受控邀请，从预览明确发布到「搭子发现」。另一账号开启接收后按地点和类别查找并申请，发起人在「我的搭子」确认。已确认后可选择「撤回并退出」。

在「消息」右上角点「站内通知」，切换「通知」「待办」「历史」。在当前通知点「查看当前状态」会向服务端核对对应对象。失权后的历史可显示「通知已不可用」。外部 URI 深链暂待实测。

## 6. Web 管理后台

用具备管理员角色、受控名单资格且当前会话有效的测试账号登录独立管理后台。进入用户列表可检索目标账号，打开详情核对身份后选择管理操作并填写理由。匹配轮次演练使用本地签名合成资格和受控运营接口，操作者需核对执行结果、版本和发布确认。

在形象审核队列查看提交内容和当前修订，填写审核结论。批准后提示用户本人另行确认发布。在举报队列打开对应受理记录，核对对象、选择分流或处理动作、填写理由，再提交。页面提示版本冲突时刷新记录，以上次实际提交的结果为准。结束后查看审计，然后退出后台。

## 7. 异常、权限和退出

网络不可用时核对本机服务是否在约定端口运行。恢复后重新读取页面，确认账号、版本和提交结果。遇到禁止访问、对象不可用或已经撤销，应返回当前入口核对资格。账号切换、退出和 Block 后，用旧入口检查私有内容是否清空，并仅保留按业务约定可见的历史状态。

个人信息入口提供用途与对象级请求说明，正式删除受理以实际可用渠道为准。当前准备稿保留注册可信离线 T0 与旧排盘兼容待裁决状态。
