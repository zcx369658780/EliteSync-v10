# 慢约会（EliteSync V2）操作手册

**登记准备稿 · Android 功能测试版 10.1.18-v2-function-p0 / 1011805 · 2026-11-21**

## 1. 软件概述

慢约会由 Android 应用、服务接口和独立 Web 管理后台组成。用户可通过应用管理个人资料、使用独立本命工具、参加符合条件的慢约旅程，或使用好友社区及 Buddy。管理人员在独立后台查看账号、处理形象审核和举报，并可查看操作审计。

测试包名为 `com.elitesync.v2functionp0`，适用于 arm64 Android。本准备稿采用独立开发包与合成服务环境，活动示范使用虚构资料。Android 源码对应提交 `36ae37206f482109e0bfc7a0f95335fc056da323`。截图统一等该包在具名设备上完成验收后采集。

## 2. 账户、资料与独立本命工具

在登录页选择「还没有账号，去注册」，填写测试账号和密码，阅读协议后提交。返回登录页输入账号和密码，进入「首页」。已选用的测试账号可从「我的」进入设置并退出。测试两组账号时，应先退出前一个账号，再登录后一个账号，并核对页面与私有信息属于当前账号。遇到会话失效，按提示重新登录。

在「我的」选择资料编辑。修改昵称、城市等资料后，提交保存并重新打开页面核对。形象草稿可独立编辑并提交审核，审核通过后由本人确认是否发布。本人可管理发布受众与分享范围。

在「我的」的工具入口打开本命功能。手动填入日期、地点和可确认的出生时刻。时刻未知时选择未知，让相应模块保留缺项。提交后等待服务端结果，离开页面再进入时读取本人记录。出现运算暂不可用或保存结果未确认时，先重读当前记录、核对原输入和版本，再决定是否继续修改。显示为 `COMPUTED_UNVERIFIED` 的结果供参考，部分模块会显示未知。

## 3. 慢约、候选与正式关系

打开「进展」，进入慢约及参与准备。按页面补充匹配输入、回答当前问卷、完成生活方式探索并确认参与意向。确认资料和报名是不同的操作。看到资格不满足时，可按提示检查准备项目或等待服务，并可回到首页使用其它合法入口。

候选发布后，从「进展」查看本轮结果，在提案页对接受、拒绝或撤回复核后提交。双方的选择分别记录。历史页可查看本人记录；当前资格、轮次或受众变化后，历史页可能只显示必要的状态。

符合条件的当前好友或连接可在接收方已开启申请时发起正式关系申请。打开「管理正式恋爱关系」，输入对方用户编号并提交，之后双方分别核对并确认。正式关系激活需要服务端核验双方当前有效的身份凭据。暂停或失权后，重新激活仍需双方确认；任一方可以结束关系。实人核验服务尚待接入，体验准备采用明确标注的 TEST_ONLY 凭据。

## 4. Connection、消息同意与私信

进入「连接与消息同意」，核对对象与当前状态，发起连接申请，由对方接受。连接建立后仍需单独申请和接受消息同意，随后可进入消息页。在对话中输入测试文字并发送，由接收方读取并核对。同意撤销、Block 或会话失效后，刷新旧列表和旧入口，界面会按当前权限显示可用或不可用状态。

本地测试包覆盖文本收发。操作期间遇到请求结果未确认，先刷新读取服务器当前状态；确认未处理时再按页面提供的同键流程继续。系统推送、联系人导入和音视频需各自具备合格服务与授权。

## 5. 好友社区、图片、Buddy 与通知

在首页进入好友社区，选择作品发布，填写标题和正文，核对受众。作品默认按当前页面的双向好友范围处理，可选择仅本人；扩大可见范围时按确认提示核对。图片先上传再发布，阅读者的当前权限、原受众和 Block 都会影响旧图片链接的可用性。查看作品后可按当前范围发表评论，评论者可在对应记录中操作撤回。受众已变化的旧评论和原图片仍依原记录及当前权限处理。

在「我的」修改头像时确认使用合成图片，上传后重新进入检查当前版本。遇到旧头像修订冲突，刷新后再提交，避免覆盖已保存的新版本。

从应用的 Buddy 入口开启搭子请求，选择活动类别，填好主题、地点类型与时间，在管理页保存草稿。草稿可以在满足条件时开放并发布到发现页；另一测试账号可按城市或类别筛选并申请，由发起人确认。退出或关闭接收后，旧链接可能只显示终态。

从首页或消息区进入「通知」，查看当前提醒、待办和历史。点击当前通知会重新向服务端校验对应对象，失权后旧通知只显示不可用状态，历史提醒保留最小必要信息。

## 6. Web 管理后台

用具备管理员角色、受控名单资格且当前会话有效的测试账号登录独立管理后台。进入用户列表可检索目标账号，打开详情核对身份后选择管理操作并填写理由。匹配轮次演练使用本地签名合成资格和受控运营接口，操作者需核对执行结果、版本和发布确认。

在形象审核队列查看提交内容和当前修订，填写审核结论。批准后提示用户本人另行确认发布。在举报队列打开对应受理记录，核对对象、选择分流或处理动作、填写理由，再提交。页面提示版本冲突时刷新记录，以上次实际提交的结果为准。结束后查看审计，然后退出后台。

## 7. 异常、权限和退出

网络不可用时核对本机服务是否在约定端口运行。恢复后重新读取页面，确认账号、版本和提交结果。遇到禁止访问、对象不可用或已经撤销，应返回当前入口核对资格。账号切换、退出和 Block 后，用旧入口检查私有内容是否清空，并仅保留按业务约定可见的历史状态。

个人信息入口提供用途与对象级请求说明，正式删除受理以实际可用渠道为准。当前准备稿保留注册可信离线 T0 与旧排盘兼容待裁决状态。
