## 四层背景

| 层级 | Token 或组件 | 用法 |
| --- | --- | --- |
| 基础画布 | `--bg-canvas` | 页面连续底色。首页、普通页面和三种盘面按路由或当前盘面选择画布。注册、输入、聊天、隐私和设置使用安静画布。 |
| 内容承载面 | `--bg-surface` | 现有文章、列表及表单输入等可读区域。原有位置、留白和边界保持，确认弹层使用 `--bg-surface-quiet`。 |
| 主题分区 | `--bg-zone`、`--bg-zone-alt` | 现有四柱、十二宫、西洋盘底以及首页进度区。几何线、分段与节点附着于原区域，状态含义仍由已有文本表达。 |
| 装饰插画 | `--bg-decor-buddy-empty`、`--bg-geometry` | Buddy 列表与已有空状态使用双图透明素材。装饰脱离内容流，触控穿透。低高度的手机预览隐藏装饰插画。表单、聊天、隐私和设置留有可阅读的净空。 |

## 画布与承载面配色

表中后缀加 `--bg-canvas-`、`--bg-surface-`、`--bg-zone-` 即为对应命名。备用分区使用 `--bg-zone-<主题>-alt`。

| 主题后缀 | 基础画布 | 内容承载面 | 主题分区 | 适用 |
| --- | --- | --- | --- | --- |
| `base` | `#EFF4F5` | `#F9FBFC` | `#E4EDF0` | 首页与欢迎页的基础画布、通知、消息列表、匹配、候选、问答、个人中心和历史列表等通用页面 |
| `quiet` | `#F4F7F8` | `#FBFCFD` | 沿用通用分区 | 注册、登录、出生资料、基础资料、展示资料、发布表单、聊天、隐私、设置和 Buddy 新建 |
| `reading` | `#F4F6F0` | `#FAFBF6` | `#E7EDE2` | 好友动态与作品详情 |
| `bazi` | `#EDF5EF` | `#F7FBF7` | `#DCECE1` / `#E6F1E8` | 我的三盘中的八字、八字详情及对应历史盘面 |
| `ziwei` | `#EDF2F8` | `#F7F9FC` | `#DCE6F1` / `#E5EDF6` | 灰蓝紫微十二宫概览、详情及对应历史盘面 |
| `western` | `#F2EFF6` | `#FAF7FC` | `#E8E0EF` / `#EDE6F2` | 淡紫灰西洋圆盘概览、详情及对应历史盘面 |
| `buddy` | `#EEF5F1` | `#F8FBF8` | 复用八字备用分区 | Buddy 列表、详情 |
| `path` | 沿用通用画布 | 沿用通用承载面 | `#E4EFEE` | 关系进度中已有的建立联系、聊天许可区块 |

首页进度区复用八字备用分区。隐私与设置的角部只用通用主题分区的几何色块。

## 背景回归

同一 393 × 852 CSS 像素视窗前后比对 24 个页面状态、250 个元素。路由、可测文字与控件属性、坐标、字号、字重、字体和文字颜色一致。头像首字与图像描述按新素材更新。

原型实走已复测首次注册与五场景 **16C / 0S / 3I / 12N**，三盘概览 **3C / 0S**，另复测历史只读、点赞回复、候选双方决定、独立联系和聊天许可、附件按原编号核对、撤权、Buddy 申请与撤回、退出换号。TypeScript 构建和四项打包测试通过。正式 Android 验收与 UI-S4 同口径成本复测仍属后续阶段。
