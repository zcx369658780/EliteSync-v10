**已确认合同**：首页一级入口仍四项；首页双频道`精选/好友`；仅具明确来源授权的官方`PUBLIC_EDITORIAL`正文可给访客读；登录有权用户可在精选读取`PUBLIC_AUTHENTICATED`用户作品或当前有权的编辑推荐原作品，在好友频道读取`FRIENDS`作品；Block、账号、作品版本/受众、媒体等分别判权。**用户公开作品≠访客内容**，任何编辑推荐不自动成为正式官方转载。

**实现范围**：官方正文/授权来源安全入口、访客有权空态、登录双频道的接口与客户端状态；按可解释时间/具名编辑标签组织，不引入参与度最大化排序或私人推断评分。必须有**真实可验证且Owner合同允许的官方内容来源**才能开放访客正文；没有时用安全空态，不能制造素材或假编辑授权。正式复制/改编用户素材给访客的转载合同/后台系统、`NEW-PC-05`首期与否仍未具名批准，**本阶段不得无许可实际转载**。

**建议AC**：
- `B1-AC1` 未登录访客对明确授权的官方正文可访问；对用户作品/互动、评论、昵称、图片缩略图、附件、用户搜索索引等返回不泄密拒绝。无授权官方内容时安全空态。

## 2. B2｜作品受众、评论策略、作者影响摘要（G02/G03、O01、SELF、CMT-T1、S15）

**已确认合同**：
- 新用户作品默认`FRIENDS + FRIENDS_ONLY`；有权好友可评，陌生人默认不可评。允许具名评论策略`ALL_ELIGIBLE / FRIENDS_ONLY / OFF`，但`ALL_ELIGIBLE`始终要求当前合法登录/作品读权和Block门禁；
- `SELF`作品只本人可读、评论默认`OFF`；`SELF→FRIENDS`如果OFF是**隐式SELF默认且作者未明确关闭**，发布前建议`FRIENDS_ONLY`供作者确认；作者**显式OFF**须保留；无法辨明来源时保留OFF并允许手动开启；
- 作者扩大作品受众之前展示受众与评论影响摘要并确认，FRIENDS→PUBLIC_AUTHENTICATED不自动将评论改为ALL_ELIGIBLE，也不允许旧评论/附件/引用自动升权。受众扩大若安全隔离无法证明则拒绝或安全停止。

**实现范围**：源头默认、服务端强制校验、显式/隐式策略来源、旧作品/旧客户端兼容保守值、作品写入/编辑/撤销与权威回执、Flutter可解释影响摘要；具体schema可由Codex选，但不能把新迁移默认为历史用户曾同意更广受众，不能在真实数据上自动回填或放宽。

**建议AC**：
- `B2-AC1` 不论旧客户端/绕过UI直接API，新作品默认受众/评论都按已接受合同；SELF只作者可读，普通新作品好友可评；作品评论关闭时服务端不可写。
- `B2-AC2` SELF→FRIENDS分别覆盖隐式OFF/显式OFF/未知来源；默认不静默越权；作者的扩大受众与评论变更独立而明确；旧评论历史受众维持原边界。
- `B2-AC3` PUBLIC_AUTHENTICATED只向**当前有权登录用户**扩大正文；前端与API+媒体+深链/通知均不让历史评论/身份被动公开；写入UNKNOWN先有权只读核验，不自动重发高影响发布。

## 3. B3｜评论者撤回、作品作者隐藏、条件独立回复与安全状态（G03、NEW-PC/EDGE/HIS/RET）

**已确认合同**：`NEW-PC-01`评论作者可撤回本人评论对外展示；`NEW-PC-02`作品作者可以在自己的作品内隐藏第三方评论展示，两种行为**不同操作主体、不同影响范围，不等于第三方原件永久删除**；`EDGE-D1`父评论不可展示后独立回复**只有可验证合法读权与非泄密上下文时**中性占位保留，否则隐藏分支而不删除回复；`EDGE-D2`仅评论者本人仍有合法必要上下文且不泄密时可获最小中性状态，复核入口**仅在实际合法机制存在时**提供，不默认通知/Push/申诉成功。`HIS-D1`历史评论读取为**原读者∩当前作品读权∩Block/账户等当前条件**，NULL/未知原受众时保守隐藏。

**实现范围**：在阶段A`original_viewer_ids`保护基础上，分主体展示控制/状态与回复自身原受众/父引用合法性门禁、当前账号/作品授权/版本回执、能合法显示的中性状态。存在旧`destroy→DELETED`路径，迁移/兼容必须避免将其假称第三方已永久删除；不得以发表评论/原评论身份自动授权另一个用户的回复或内容、无需为各回复创建独立Owner审批。

**建议AC**：
- `B3-AC1` 评论者撤回与作品作者隐藏使用不同授权/展示语义；非法第三人、撤销/Block/旧版本不可越权，UNKNOWN先只读核权威结果；隐藏不修改他人的原始数据权利。
- `B3-AC2` 父评论隐藏、父评论作者撤回、双方先后操作、原读者变化、内容自身带父引用/昵称泄密时：仅可证明合法的独立回复在安全中性结构下阅读；不合法时隐藏分支、原回复保留。
- `B3-AC3` 本人中性状态不透露谁隐藏、谁Block、举报方、关系或理由；无真实复核机制时不造工单/期限/恢复承诺；旧NULL评论、历史引用与第三方媒体均不因当前作品扩大受众重显。
