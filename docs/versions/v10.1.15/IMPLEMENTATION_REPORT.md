## 实现

五题分别覆盖居所声音、旅行安排、空闲活动、共餐人数和相聚时间。每个分类值保存来源scene、option、answer_revision、rule_id及说明。修改后从当前答案重新计算全部映射。摘要保持可纠正，规则采用有限分类。

注册复用服务端返回的设备绑定会话，并沿既有会话持久化与过期合同建立登录。新用户默认进入欢迎页，可跳过进入首页及社区。我的页面和慢约会准备页提供再次进入入口。

后端新增两张附加表。当前数据保存题库版本、原始答案、状态、完成时间、映射版本和修订号。命令表保存请求摘要、动作及应用修订，不保存旧答案快照。重复请求返回当前最新投影。修订冲突返回409，客户端保留待同步项并提供明确的放弃本机项/读取最新操作。重做清除当前答案、派生结果及旧命令回执，修订持续递增。

APP先把单项待同步命令写入既有平台加密存储，再发送API。存储绑定账号、设备、会话及登录时间。冷启动恢复沿既有在线核验合同，新增的可恢复键仅为 `lifestyle-discovery-draft:v1`。保存期间锁住场景导航，过期账号响应受会话检查拦截。

每周慢约会门禁使用当前完成状态，服务端覆盖报名和新周期各权威阶段。既有通用资料准备状态与已揭晓proposal的协调逻辑继续沿原合同。题库答案及派生值均未加入匹配评分、候选排序、peer展示或关系状态转换。
