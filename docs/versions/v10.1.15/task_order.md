## 四、六项AC

### AC15-01 题库与偏好维度设计

- 设计4—6个生活场景，每个场景2—3个可理解、互不羞辱、不带道德高低判断的选项；
- 可参考居住环境、旅行方式、周末节奏、用餐/社交环境、休闲活动、长期生活偏好；不要求全部使用，避免题目重复；
- 每个选项映射到有限、清晰、可解释的生活方式维度；
- 题库、场景、选项和映射规则必须有版本号；
- 记录原始选择、映射维度、来源规则和解释；不推断疾病、人格障碍、政治/宗教倾向、经济等级或其他敏感属性；
- 不将结果直接转换为MBTI类型，不宣称科学诊断或准确人格画像；
- 形成`LIFESTYLE_DISCOVERY_QUESTION_BANK_V1.md`和机器可读配置/映射，测试可覆盖每个选项。

### AC15-02 美术资产与动画

- Astra优先负责艺术指导、构图方案、提示词和跨场景一致性审阅；
- 使用生成时最新可用的在线GPT Image模型制作正式素材；记录精确模型名/版本、生成日期和提示词；
- 目标为每个场景有一张主场景插画，并为选择状态提供必要的可视差异/分层素材；优先复用背景和图层，不无意义地生成大量重复图片；
- 风格严格遵守Owner已冻结的低分辨率质感、几何色块、低刺激配色、二次元卡通/构成主义，不使用写实摄影风格；
- 场景切换、选项反馈、返回上题必须支持正向和反向动画；
- 音乐如纳入，必须轻柔、默认不强制播放，提供静音；尊重系统减少动态效果设置；
- 素材优先本地打包，不在运行时调用图像生成服务；
- GitHub资产路径：`design/assets/lifestyle-discovery/v1/`；包含优化素材、预览、提示词、模型元数据和SHA256 manifest；
- 图片文件需压缩、尺寸适配、避免超大仓库；大文件先评估，未经Owner同意不启用付费服务/Git LFS；
- 如果模型不可用，提交prompt pack和`ASSET_GENERATION_PENDING`状态，不得偷偷用不明来源素材替代。

### AC15-03 注册欢迎体验与跳过

- 新用户账号创建成功后，默认进入Lifestyle Discovery欢迎流程；
- 用户可以明确选择跳过，跳过不回滚账号创建、不限制普通社区访问；
- 用户中途退出或杀进程，已完成场景答案和进度自动保存，重进后可继续；
- 支持返回上一个场景、修改选择、动画倒放/反向过渡；
- 完成后生成偏好卡片/摘要，允许用户查看、纠正、重新探索；
- 不要求注册时填写真实姓名、出生时间、出生地点或信用数据；
- 不申请与此功能无关的Android运行时权限。

### AC15-04 偏好数据持久化与隐私

- 后端保存题库版本、原始答案、完成状态、完成时间、偏好映射版本；
- 采用最小必要字段，遵循现有鉴权、账号隔离和私密资料边界；
- 用户修改答案后重新计算映射，保留合理版本历史或审计，避免旧结果覆盖新答案；
- 未完成/跳过与已完成必须有不同状态；跳过不能被误标记为完成；
- 删除/重置功能按现有账号数据删除合同处理，不额外扩大保留范围；
- 不将偏好答案上传到外部AI，不用于私聊分析、广告或非授权排序。

### AC15-05 每周慢约会匹配资格门禁

- 仅每周慢约会匹配申请/进入匹配周期需要Lifestyle Discovery完成；
- 未完成时APP给出清晰、低压力的下一步入口；
- 后端必须强制检查，不能只做客户端按钮隐藏；
- 跳过或未完成用户仍可登录、访问匿名社区、使用普通社交及允许的非匹配功能；
- 不把此门禁扩展到Buddy、社区、好友或普通聊天；
- 不改变既有匹配算法、候选排序、Connection、Messaging Consent、Conversation或Relationship状态机；
- 身份核验仍是独立未来门禁，不在本版接入真实供应商，也不将Lifestyle Discovery完成等同于实名。

### AC15-06 集成、验证与交付
