## 2. 阶段B1 / v10.1.15授权

Owner指示“请继续”，本补充据此授权只启动阶段B1 / v10.1.15「生活方式探索与渐进式偏好」。

目标：
- 注册后默认展示Lifestyle Discovery欢迎体验，但允许跳过；跳过不阻止注册成功或匿名社区使用；
- 用户未来参与每周慢约会匹配时必须完成生活方式探索；
- 初始探索设计4—6个生活场景，每个场景2—3个选项；题库和映射在v10.1.15中设计并版本化；
- 允许返回、修改、动画反向过渡、自动保存进度和冷启动续做；
- 记录原始答案与可解释偏好映射，允许用户纠正；
- 这是一种轻量生活方式偏好探索，不是正式MBTI、心理诊断或临床判断。

本次仅授权B1，不授权B2统一状态与后台自动化中心、B3全局低操作成本重构、B4运行时AI关系辅助或阶段C外部服务/发行准备。

## 3. 美术资产生产工作流

Owner新增偏好：未来视觉设计优先使用Astra模型进行艺术指导、构图/风格探索、提示词和一致性审阅；使用当时最新可用的在线GPT Image模型生成正式美术素材；筛选后的素材放入GitHub，由Codex按固定路径/manifest直接调用。

v10.1.15可为Lifestyle Discovery准备首批美术资产，但不得改变已确认风格：
- 低分辨率质感、色块分区、几何构成、低刺激配色；
- 二次元卡通/构成主义场景；
- 避免写实人像、过度线条、高饱和、闪烁和快速镜头刺激。

每个资产必须记录实际模型名/版本（不能只写latest）、生成日期、提示词、尺寸/格式、用途、优化处理、SHA256、文件大小和权利/服务条款依据。禁止将用户个人资料、偏好答案、出生信息或私聊内容放入生成提示词。GitHub建议路径：`design/assets/lifestyle-discovery/v1/`；manifest和prompt一并保存。大文件先优化并评估仓库容量；未经Owner同意不得启用新付费存储或Git LFS。

若Codex无法使用指定模型或在线GPT Image，应准备可复用的提示词和资产需求清单，明确标记`ASSET_GENERATION_PENDING`，不得静默换用不明模型、随机图库或未经许可的素材。

## 4. 继续有效的产品边界

- 不接运行时AI分析，不向外部模型发送用户偏好；本版使用可解释的本地规则映射。
- 不收集真实姓名、证件、精确出生时间/地点、信用分或蚂蚁积分。
- 不接身份核验、征信、芝麻信用、积分、真实Push、支付或其他新供应商。
- 不把生活方式探索称为MBTI测试结果或确定性人格标签。
- 不将完成探索设为注册、登录、社区、Buddy或普通内容访问的门槛；只作为每周慢约会匹配的必要前置条件。
- Match、Connection、Messaging Consent、Conversation、Relationship继续独立。
- B2/B3/B4和阶段C仍未授权。
