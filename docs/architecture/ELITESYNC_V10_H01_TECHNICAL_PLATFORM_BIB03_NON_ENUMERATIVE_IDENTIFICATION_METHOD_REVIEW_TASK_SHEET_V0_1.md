## 3. Proposed BIB-03 method model

The only method model that may be reviewed is:

`BIB03-METHOD-01 — PREDECLARED FINITE EXACT-PATH PROBE METHOD — METADATA ONLY — NON-ENUMERATIVE — FAIL CLOSED`

This method model means only:

1. a later separately authorized execution task sheet must predeclare every exact path hypothesis before execution;
2. hypotheses may not be generated by repository listing, directory listing, code search, wildcard search, broad filename search, source-content search, or inspection;
3. each probe may ask only whether one exact predeclared path resolves at one immutable commit and, if it resolves, may capture non-content Git identity metadata sufficient to form a candidate identifier;
4. the method may emit at most one concrete candidate identifier;
5. zero hits fail closed;
6. more than one hit fails closed;
7. no fallback search or hypothesis expansion is allowed within the same invocation;
8. method output does not accept, bind, inspect, or read the candidate.

`REPOSITORY + IMMUTABLE COMMIT SHA + EXACT REPO-RELATIVE PATH + GIT BLOB SHA`
