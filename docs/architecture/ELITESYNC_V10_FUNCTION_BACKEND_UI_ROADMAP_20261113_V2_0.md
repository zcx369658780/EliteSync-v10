# EliteSync v10 功能后端与集中 UI 路线图

版本：2.0。日期：2026-11-13（北京时间）。  
依据：[Owner最新决定](../decisions/OWNER_V10_1_5_CLOSEOUT_AND_BACKEND_FIRST_20261113.md)。  
当前：项目交接完成；v10.1.5收尾并结转剩余项；v10.1.6 R1及[v10.1.7六项AC](../versions/v10.1.7/ADVISOR_ACCEPTANCE_20261113.md)均按约定开发范围获顾问及Owner接受；[v10.1.8通信与通知任务](../versions/v10.1.8/task_order.md)已授权下达，本地实施尚未回报。  
本路线替代2026-10-19路线图的未来版本划分、运营展望和阶段执行安排，不重写历史实现与验收。

## 一 产品终点与实施顺序

整个 v10 完成一个功能完善、可持续使用的开发产品：统一的 APP、真实产品 API、持久数据库、必要的独立 Web 管理面板。先完成各业务功能和最小可操作界面，再集中打磨 UI、信息结构与文案。v10不安排公司注册、真实内测、收费、真实线下运营或正式发布，也不以版本号到达某点自动触发这些工作。

“后端真实”按实际业务链判断，不按是否使用 Docker 判断。正常 APP/Web 操作必须产生真实持久状态；虚构账号可用于验证，夹具或受控响应不能冒充最终用户流程。既有 Laravel/MariaDB/WS/SFU 开发架构继续复用，不为功能落实另造后端或迁移环境；具体资源状态以带时间回执为准，SFU故障仍按后文结转。

普通功能版需要足以完成操作的界面、错误反馈和输入保留；整体布局、视觉风格和文字统一集中在v10.1.12。全局UI后置不意味着保留假按钮、不可操作页面或假成功提示。

## 二 版本划分

| 版本 | 目标 | 主要工作 | 用户可观察出口 |
|---|---|---|---|
| **v10.1.6** | **真实后端接续与资料展示闭环** | 本版资料旅程统一真实入口；资料/可选照片/展示草稿；真实审核、反馈、重提、发布、撤回；获准对象资料页；最小扩展接口 | 本人正常编辑提交，Web实际处理，本人主动发布，对方从获准入口看到正确版本；重登重启保持 |
| **v10.1.7** | **婚恋偏好与匹配旅程** | 统一必要资料、关系意图和择偶偏好；复用现有20题、consumer和轮次；整理筛选/排序依据；候选解释、等待/无候选/失败恢复、历史与暂停退出 | 从普通输入经过真实后端生成候选并作出选择，不靠注入提案代替主链 |
| **v10.1.8** | **通信与通知功能完善** | 收束现有聊天路径；搜索/未读/消息状态/引用回复；补语音留言最小链；站内通知；现有媒体/RTC可靠性及SFU结转项 | 双端正常文字、图片、短视频、语音留言和通话可用；失败恢复、重试与通知目标可信 |
| **v10.1.9** | **好友社区搭子与活动整合** | 联系人选择取代内部ID；社区作者与真实收藏；好友互动；吃饭/学习搭子；有限城市/主题活动发现；平台活动报名候补取消与后台处理 | 普通用户能从发现或邀请进入活动并完成约定生命周期，数据真实保存 |
| **v10.1.10** | **自我认识与特色工具产品化** | 复用MBTI、三盘和已有手填动态/双人盘；补实际缺口；输入、计算、历史、重新计算、基础解释与高级参数分层 | 本人可正常使用、重读和管理已选特色工具；计算与解释来源清楚 |
| **v10.1.11** | **账号支持与功能质量收口** | 补账号恢复等未闭环软件、隐私设置、帮助/反馈真实记录、对应后台；必要通讯/离线安全封装；跨模块功能断点 | 注册使用到退出/恢复的约定开发链完整；支持和后台能处理本版真实业务 |
| **v10.1.12** | **集中 UI 信息结构与文案完善** | 四入口职责、组件/密度/字体/颜色/主题、普通与高级信息分层、返回与键盘、大字和可访问性、全状态文字；有限联合回归 | 同一候选的主要旅程顺畅、一致，用户知道当前状态和下一步 |

版本编号与范围由顾问按Owner授权确定。v10.1.6及v10.1.7已按约定开发范围接受；依据[本次决定](../decisions/OWNER_V10_1_7_ACCEPTANCE_AND_V10_1_8_AUTHORIZATION_20261113.md)，v10.1.8已授权下达，具体默认值与六项AC见[计划](../versions/v10.1.8/plan.md)。v10.1.9及后续仍为规划，按实际交付和验收结果具体化，必要时合并或小幅调整，但不退回重复恢复或旧微任务审批流程。

## 三 范围说明

### v10.1.6

完整范围以[计划](../versions/v10.1.6/plan.md)和[任务书](../versions/v10.1.6/task_order.md)为准。“真实主链接续”只覆盖资料与展示旅程必要的入口和服务配置，不是一次全APP重构。当前真实聊天、慢约、好友、正式关系等能力保留。

本版加入最小的自愿展示照片能力，复用现有私有媒体存储和鉴权；不建设公开相册、滤镜、视频主页或全站人员搜索。婚育/异地等择偶语义在1.7与匹配一起完善。

### v10.1.7

完整范围以[计划](../versions/v10.1.7/plan.md)和[任务书](../versions/v10.1.7/task_order.md)为准。复用现有20题、consumer和轮次/提案，统一关系目标、双方年龄/地域条件及当前有效问卷排序，补齐普通候选生成、失败恢复和本人历史。新增可选本人资料不自动成为筛选条件或公开展示。普通慢约不再依赖星盘计算成功，既有特色工具保留。

必要资格、本人主动偏好及解释信息分别处理；具体默认值由本版计划冻结，不能把旧168小时开发默认推导为全站每周一次。人格/玄学和Safety记录不自动成为权威兼容性分数或普通硬筛选；v10.1.6 R1的当前受众规则继续覆盖新历史入口。

### v10.1.8

完整范围以[计划](../versions/v10.1.8/plan.md)和[任务书](../versions/v10.1.8/task_order.md)为准。沿当前真实聊天链补已读事实、当前会话有界搜索与引用回复；语音留言为1–60秒/5 MiB，真实录制、预览、明确发送与对方播放，复用私密媒体与音频资源保护。站内通知补匹配决定、CN/MC及本人审核结果，保留消息/通话并修正终态提醒；真实Push保持供应商未接入边界，不将test_only记为真实送达。

SFU当前普通通话和一次故障后的新合法通话须验证可用，安全退出不等于通信PASS。历史非注入超时精确根因可以继续UNKNOWN，按具体新线索有限诊断，不循环等复现；当前功能若仍不可用，对应AC记PARTIAL，其余工作继续。一次本来需要的新撤权验证沿既有停媒合同，补提交上端后完整至少5秒尾窗，旧call51记录不重写。

### v10.1.9

扩展的是用户自愿发布的最小搭子活动卡发现，不开放可枚举的全球个人资料目录。城市与主题只用于获准活动用途，具体可见字段、受众、期限与请求限制在本版定义；活动发现不自动授予好友或消息同意。沿用吃饭、学习，其他场景按真实需要加入，不同步建立大型群聊/直播平台。

已有平台活动软件继续完善；虚构活动和模拟预算不变成现实订场、付款或到场认证。

### v10.1.10

优先完善已有计算与工具，独立精度/数据许可限制继续准确记录。新的跨账号关系解释、读取对方出生信息、AI关系推进和新商业服务只保留接口，不借“特色工具产品化”重新加入本轮后置范围。已有手填双人盘不删除，也不将Comparison改名为真正Composite。

### v10.1.11与v10.1.12

1.11只处理实际功能、当前通信/离线保护和跨模块风险，不新增庞大治理框架或全量历史考古。真实短信/身份等外部依赖尚不可用时，内部流程与外部接入分别记录，不制造成功。

1.12集中改UI和文字，建议按“我的/设置 → 消息/聊天 → 首页/进展 → 匹配/社交/特色工具 → 必要Web页面”推进。此时不再新增大型业务；若发现阻碍正常使用的实际功能缺陷，可在同版修复。选取关键页面与状态检查，不重拍全部历史截图或重跑全部设备组合。

## 四 相识后功能只保留接口

新增破冰推荐、约见安排、共同计划、纪念日提醒和长期关系陪伴暂不做业务实现。保留最小服务/能力扩展契约：参与者与合法上下文、授权用途、数据归属、撤回要求、当前不可用状态及未来接入点。

不建设空业务表、自动任务或假成功API，不把未实现接口作为普通用户可点击功能。已有联系/消息许可、聊天、搭子、平台活动、正式关系申请/确认/暂停/恢复/结束、已有关系盘保持原有能力与独立语义。

## 五 结转事项

| 事项 | 承接位置 |
|---|---|
| 非注入SFU超时、硬件音频与复杂路由 | v10.1.8相关通信质量；按具体新信息或受影响变更诊断 |
| call51计时余量、完整5秒尾窗不足 | 下一次本来需要的停媒验证中补完整参数与尾样本 |
| 真实Push | v10.1.8通知适配；实际供应商投递单列PENDING |
| 真实身份核验 | 现有资格/正式关系接口保留；真实接入另行决定 |
| 自然15/30天、未覆盖设备、独立盘面精度 | 相应模块与1.11必要质量工作，不变成全项目暂停 |
| 作者占位页、非持久按钮、两套构建路径 | 按1.6—1.11对应功能接线，1.12统一视觉文字 |

v10.1.5历史冻结记录原样保留，Owner已决定阶段收尾。旧G2和已退役执行器不恢复。

## 六 执行与交付方式

Codex在当前稳定目录和既有会话自主拆解，每版连续完成后端、持久化、必要管理端和APP消费端，再集中交付。普通修复、开发库迁移、定向验证、必要APK和双模拟器沿用长期授权，不逐动作请示。仅新增改动、失败或具体风险扩大验证。

每版一个简洁实施报告和必要候选身份，说明用户功能、实际运行链、检查、未完成项与最小后续动作。功能声明按实际软件链判断，不按页面数、接口数或测试数。同步失败记PENDING_SYNC，保护本地成果，不因备份失败停止其他已授权工作。

当前工作流见[CURRENT_WORKFLOW](../workflow/CURRENT_WORKFLOW.md)。本路线不授权main合并、手机、生产/真实数据、新供应商或费用、系统提权、内测、运营或正式发布。
