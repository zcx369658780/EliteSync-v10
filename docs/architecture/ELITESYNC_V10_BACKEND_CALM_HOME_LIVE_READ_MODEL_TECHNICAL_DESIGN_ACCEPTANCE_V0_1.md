## 2. Accepted Home contract

The accepted projection contains exactly three semantic sections:

- `Current state`;
- `Next decision`;
- `Optional support`.

Each item preserves its source-domain identity, authority provenance, subject/participant binding, audience, Home purpose, source lineage/revision/currentness, usable freshness, and exact source-local condition.

Home creates no global revision and no global lifecycle.

## 3. Accepted primary-action rule

Primary-action selection is presentation filtering only.

- zero valid actor-relevant candidates => no primary action;
- exactly one valid candidate => it may be shown as the sole primary action, subject to source-writer revalidation;
- multiple valid candidates => one may be selected only when separately accepted product authority establishes a unique Home precedence for those exact candidates;
- otherwise Home returns no primary action rather than inventing a cross-domain ranking.

Home must not break ties using timestamps across domains, revision numbers, arrival order, private content, unread/activity counts, countdowns, Compatibility totals/factors, Safety evidence, engagement predictions, model output, inferred desirability, or person worth.

## 4. Partial availability and propagation

Each source fails independently.

Unknown, unavailable, stale, superseded, incomparable, mismatched, or projection-lagged evidence affects only its own source contribution. Another valid source cannot repair, refresh, or replace it.

Correction, revocation, supersession, and newer current evidence propagate only within the exact source scope and cause Home to recompute affected display/action selection without rewriting another domain.

## 5. Privacy and non-substitution boundaries

The accepted design excludes:

- private Conversation messages, previews, drafts, unread/private thread details;
- hidden Safety evidence;
- Compatibility total scores;
- unrelated Profile/Showcase enrichment;
- analytics/model-training/ranking signals;
- unaccepted AI/personality/astrology/reference-signal inputs;
- route/cache/notification/transport/legacy identity as authority.

Navigation remains separate from access authority. Permitted actions remain descriptive and non-self-authorizing.
