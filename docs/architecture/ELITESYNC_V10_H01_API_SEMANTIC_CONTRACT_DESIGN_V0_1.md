## 5. Semantic vocabulary and meaning-authority boundary

| Term | Exact semantic use in this artifact | Meaning authority boundary |
| --- | --- | --- |
| Participating User | Either User who is a participant in the exact reciprocal Connection | A User remains a person with agency, not a technical representation, score, or inferred person truth |
| Closure intent | The participating User's `User-authored` choice that the exact Connection no longer carries that User's authority for future optional continuation | Custody, visibility, technical availability, or another participant cannot author this choice for that User |
| Affected Connection | The one existing reciprocal Connection to which the closure intent applies | It is not every Connection, the User, the account, a Relationship, or a global restriction |
| Closure effect | The technology-neutral loss of authority for future optional continuation under the affected Connection, together with governed withdrawal/invalidation boundaries | It is not a statement about execution timing, mechanism, delivery, persistence, or empirical effectiveness |
| Dependent ordinary effect | An ordinary-domain effect whose authority depends on the affected Connection and whose withdrawal or invalidation is already governed | This term does not create or enumerate a technical dependency |
| Safety control directive | The minimum-necessary control meaning permitted to cross into ordinary affected-scope enforcement | It is not Safety evidence, reasoning, allegation, finding, or person truth |
| Prior receipt | Information already received before closure under then-current authority | Closure creates no recall or retroactive-erasure promise |
| Independent authorship | Information authored by the other person under that person's own meaning authority | Closure does not rewrite that authorship |

Product, Domain, and Information authority govern every meaning above. API, Database, Backend, Flutter, storage, runtime, and implementation custody can never create or redefine human meaning merely by representing, carrying, processing, retaining, or displaying it.
