The dispositions mean:

- `KEEP`: bounded current responsibility can support the target, subject to later implementation acceptance;
- `REFACTOR`: responsibility remains useful but ownership, contract or guard must change;
- `REPLACE`: target semantics require a different contract before the current seam can cease owning behavior;
- `REMOVE`: remove only after named replacement/cutover gates, never merely because source exists;
- `DEFER`: validly postponed; it is not missing;
- `UNKNOWN`: current evidence does not establish the fact within authorized scope; it is not absent.

Mandatory interpretation rules remain:

`CURRENT SOURCE EXISTS != MUST KEEP`

`DEFERRED != MISSING`

`UNKNOWN != ABSENT`

`LOCAL TOOLING BLOCKER != PRODUCT DEFECT`
