## 2. Semantic vocabulary and precedence

- **Invocation**: one boundary occurrence of `authorConnectionClosure` for one exact Connection; an invocation may present authored closure intent but is not itself that intent or the closure effect.
- **Authored closure intent**: one participant's `User-authored` consent/control choice that the exact Connection no longer has that participant's authority for future optional continuation.
- **Already-established closure effect**: the exact Connection's loss of authority for future optional continuation; it is not an invocation, authoring event, API proof, Backend proof, or persisted fact automatically.
- **Repeated authoring**: a later invocation in which a participant again authors closure intent for the same exact Connection.
- **Reaffirmation**: the same author's semantic restatement of continuing closure intent after the closure effect is already established.
- **No-new-effect**: the classification that a later authored intent creates no additional, broader, duplicated, reopened, or reversed closure effect because the exact effect is already established.
- **Reopening/reversal**: a distinct authority-changing meaning that is prohibited from arising automatically and is not expressible merely by repeated invocation, repeated authoring, reaffirmation, or no-new-effect.

These meanings are distinct and must not be silently treated as synonyms. Product/Domain/Information meaning continues to outrank technical representation.
