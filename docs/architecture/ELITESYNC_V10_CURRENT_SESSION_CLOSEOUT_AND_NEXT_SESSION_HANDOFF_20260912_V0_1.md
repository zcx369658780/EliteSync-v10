## 3. Current Owner-approved product target

EliteSync remains a Relationship Decision Support System.

Preserve:

`Match != Connection != Conversation != Relationship`

Highest constraints:

- Privacy;
- Safety;
- User Control.

Supporting constraints:

- Explainability;
- Reliability;
- Fairness;
- Auditability.

AI output is not verified truth, relationship authority, guilt authority, or autonomous Safety authority. Safety evidence is not ordinary Compatibility/Ranking/public-reputation evidence. Private Conversation is not default training/ranking data.

## 4. Owner-approved APP direction

The Owner accepted the proposed design direction on 2026-09-12.

Target MVP top-level navigation:

`Home | Progress | Messages | Me`

Key accepted decisions:

- Home becomes a low-density Calm State Hub;
- Discover leaves MVP top-level navigation and becomes a Phase-2 secondary Explore/Support Library;
- Progress is a navigation container only and must preserve distinct Match, Connection and Relationship semantics;
- Match requires explicit opt-in and does not create Connection;
- Connection requires separate mutual consent;
- Conversation requires ACTIVE Connection plus separate messaging consent;
- Relationship support is Phase 2 and mutual opt-in, never inferred from Conversation behavior;
- no globally public Profile in MVP;
- Private Identity, Matching Inputs, Readiness and Showcase are separate purpose/lifecycle surfaces;
- no single authoritative Compatibility total score in MVP;
- private Conversation is not default AI/training/ranking input;
- canonical Match is the forward path;
- participant-linked legacy Match is a retirement/migration concern after bounded consumer inventory and replacement readiness.
