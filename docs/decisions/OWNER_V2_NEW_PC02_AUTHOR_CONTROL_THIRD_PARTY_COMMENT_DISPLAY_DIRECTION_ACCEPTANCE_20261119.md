## 2. 已接受的最小产品方向（OWNER_CONFIRMED）

1. **管理对象和权限归属**：作品作者可以管理**本人作品内**第三方评论的展示，具体可考虑对单条第三方评论执行隐藏；这是作品内展示管理权，**不是**评论者原始数据所有权或替评论者行使永久删除请求权。
2. **隐藏与删除分开**：隐藏第三方评论的作品内展示，不等于删除评论者的原件、媒体、安全/申诉所需的合法独立记录；不得向用户误报“评论及所有备份已被永久删除”。
3. **必要的安全复核与申诉原则保留**：展示管理不能成为自动擦除举报、安全证据或规避合法处理的途径。具体谁能发起复核、收到什么通知、何时恢复、如何限制滥用，仍待单独细化与适用合法依据。
4. **不改变既有权限规则**：读者即便能看到作品，也仍须遵守原评论受众∩现行作品读权和Block等条件；作品作者不能借评论隐藏/恢复为第三方扩大原有受众。
5. **O09 / RET既有安全语义继续有效**：高影响写入UNKNOWN先有权只读核对权威结果，不自动重放；展示权限变更/隐藏、删除请求受理和删除完成分别记账，不得用静态概念推断真实后端已实现。
