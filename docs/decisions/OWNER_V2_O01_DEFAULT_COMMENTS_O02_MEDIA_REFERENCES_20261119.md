## 2. O01｜用户新作品默认评论策略 = FRIENDS_ONLY

- 新建用户作品的既定默认受众继续为`FRIENDS`；**默认评论策略为`FRIENDS_ONLY`**。该默认值不要求用户每次发布前单独打开评论设置。
- 作者仍可按既定选项主动选择`ALL_ELIGIBLE`、`FRIENDS_ONLY`或`OFF`；评论有效条件至少包括当前有效账号、作品仍有权可见、当前作者评论策略允许、无Block，且通过适用的服务端门禁。
- 作品从`FRIENDS`扩大至`PUBLIC_AUTHENTICATED`时，**不自动将评论策略从`FRIENDS_ONLY`扩大到`ALL_ELIGIBLE`**。作者若希望新合法受众评论，需要另行明确修改评论策略，不悄然扩大权限。
- `SELF`作品的具体评论行为或默认OFF规则、作者逐条设置是否记住上次选择、旧作品迁移默认值及评论策略更改后的已存在评论处理，**本次没有逐项裁决，仍为OPEN**。
- `ALL_ELIGIBLE`也不等于匿名访客可以评论；访客仍仅能只读已授权官方正文，不读用户作品或官方专题评论，不做站内互动。

## 3. O02｜历史评论本体、附件与引用保持原受众边界

- 已发布`FRIENDS`作品扩大为`PUBLIC_AUTHENTICATED`时，**此前好友评论（文字、图片、视频/文件附件、预览缩略图、嵌入引用、被引用片段及与其关联的可识别身份）不能因作品受众扩大而被自动公开**。
- 新有权读取作品正文的登录用户，未必具备旧评论/附件/引用的阅读权；读取评论详情、媒体下载、引用预览、外链跳转、通知、缓存和搜索摘要等仍必须守住相应历史评论受众/Block/当前权限限制。
- 如果新公开页面引用了仍受限的历史评论或媒体，不得通过缩略图、引用预览、URL直达、临时媒体地址或不同客户端缓存来绕过权限；应隐藏受保护片段或采用不会泄露身份/内容的占位（具体交互尚待合同细化）。
- 无法可靠将作品公开受众与旧评论/附件的受众隔离时，不能在没有安全处理的情况下执行扩大公开；应限制操作或在安全、可理解的产品流程中让作者选择符合既有权限的处理方式。本决定**不授权作者单方面替旧评论参与者扩大评论阅读权**。
- 作者自行上传的作品媒体与**他人旧评论附带的媒体/引用**需要按各自有效来源和受众规则核验，不能把两者混为同一个公开授权。
- 原始历史评论是否保存/删除、保留多久、已读权限变化后记录何时清理、媒体URL时效/签发技术和引用关系数据模型均保持OPEN，不因此承诺自动删除或永久保存。
