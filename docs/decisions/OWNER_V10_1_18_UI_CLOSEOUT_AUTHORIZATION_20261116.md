## 三、v10.1.18范围

1. 清理用户可见开发式/程序式文案，统一产品语言；
2. 将一级「进展」朝「匹配」方向调整，聚焦匹配结果和用户可执行事项；
3. 统一按钮、选项在默认/按下/选中/禁用等状态下的配色与文字对比；
4. 提高自动化入口可发现性，但只保留一个规范授权与控制页面；
5. 将持续性说明、免责声明和用途解释收敛至合适的权限/说明页面，并在首次参与匹配时提供必要的一次性上下文说明；
6. Buddy匹配问题独立诊断，保持与恋爱匹配分离，不以UI任务名义擅自重做算法；
7. 补充同一安装内账号隔离与真实冷启动验证，尤其是退出、切号、强制停止、重启后的状态/消息/通知隔离。

具体AC、验收边界和执行要求以v10.1.18 task_order、plan、DEVELOPMENT_ALIGNMENT和产品合同为准。
