## 2. 本次接受的最小规则

1. **主体与对象**：评论作者可主动表达撤回**本人所发表单条评论**的当前对外展示的决定，前提是当前身份、对应对象与可执行权限成立。不是作品作者或平台代其决定。
2. **展示撤回的含义**：在权威结果确切确认后，相应评论停止向原本有权阅读其作品内展示的受众外显；操作结果未知时只能保持UNKNOWN并先有权只读核验，不假称撤回完成或自动重放。
3. **不代表物理删除**：撤回展示不自动永久删除评论原文、附件、媒体、合法独立留存、安全/申诉资料或所有备份；真实删除请求的受理/完成继续遵守RET-D1/D2。
4. **独立他人权利**：撤回本人评论不自动删除、撤回、篡改其他用户的独立回复/原始资料，不自动改变作品的受众或其它作者的合法权利。
5. **现有权限约束不变**：原评论受众与当前作品读权交集、Block和现行权限仍优先；旧通知、引用、缓存、媒体URL不得借撤回/恢复路径绕过已有权限。评论者自己的撤回权与NEW-PC-02作品作者隐藏他人评论的作品内展示管理权相互独立。

## 3. 明确保留的OPEN

- **评论树、引用、通知**：撤回后是否显示安全占位、如何关联第三方回复、旧通知与引用如何安全处理；不得把隐藏引用误当已物理清除全部第三方合法记录。
- **恢复/编辑**：评论作者能否恢复展示、重新发表、编辑旧评论，以及历史版本和争议处理。
- **安全、申诉与合法保留**：举报、法律请求、独立安全记录、适用期限、权利冲突如何界定；不能凭方向性决定生成期限、后台角色或法定例外。
- **实现证据**：实际评论ID/作者身份与权限、写入回执、幂等/UNKNOWN只读、跨设备/旧媒体缓存与存储迁移及实机动态QA均尚未核查。
