## 2. 四项已认可原则（Owner确认，细节合同未冻结）

### A67-R1｜内容失权和账号/反馈资格失效相互独立

- 对某位用户、聊天、作品、资料等发生失权时，受保护正文、媒体及私密标识立即隐藏；不能为了截图、反馈或返回而保留。
- 内容失权本身**不自动等于**当前账号被注销或无资格反馈。当前登录账号仍有合法反馈资格时，可保留无敏感信息的主动反馈入口；账号本身已退出、失效、被限制或无资格时不得站内提交。
- 反馈流程不自动附带受保护的历史截图、日志或他人信息。

### A67-R2｜失效通知退出可操作待办

- 过期、被撤回、已不再可处理或失权的事项立即移出当前可操作待办，原“接受”等操作不得保留。
- 如果当前权限允许展示**不泄密的历史摘要**，可作为普通通知显示“已失效/不可处理”；否则隐藏相应内容及预览。
- 已读/未读与业务是否待处理保持独立；聊天和通知未读仍分开。标读触发时点、历史保留政策仍OPEN。

### A67-R3｜用户可补资料与真实核验供应商未接入分离

- Lifestyle五场景，每题三选项；注册阶段可以跳过，正式真实匹配前必须完成。
- 可补足的Lifestyle/合法资料缺项可以显示下一步；未接入真实身份核验服务必须显示为外部依赖“暂不可用”，不能表现为用户再完成一步就能通过，也不能开放真实匹配报名。
- 候选/Connection/聊天的未来示例不代表现有账号可以完成此整条真实路径。

### A67-R4｜跨入口执行统一的“事实先行”设计检查

- 统一交互展示顺序：当前账号及访问权 → 当前业务状态/有效版本 → 合法用途、展示受众及已发布快照（视任务适用）→ 唯一清晰的合法主操作 → 安全返回和异常恢复。
- 写入结果UNKNOWN必须先查权威状态，不能自动重复提交；旧通知/深链/系统Back/迟到响应不得绕过权限。
- 此处只确定**交互一致性规则**，不授权新建Personal Data Hub、数据库schema、统一接口或服务分层。
