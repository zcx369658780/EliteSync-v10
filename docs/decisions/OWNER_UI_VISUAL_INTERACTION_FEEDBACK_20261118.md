## 1. Owner明确反馈和同意的方向（OWNER_CONFIRMED）
1. **构成主义+二次元的原始目的首先是降低信息密度、减少视觉疲劳**。构成主义几何组织版面而非让每个角落出现装饰；二次元动漫场景应为页面用途服务，不能使功能页变宣传海报。首页、访客内容中的适量场景插图可保留。
2. 高亮白底+红色强对比易产生疲劳；转向**偏暗、低刺激的蓝/绿/灰青主色**，并把大面积纯白背景替换为**柔和淡绿、淡蓝、灰青底色**，特别考虑下班后晚间使用。保留文字可读性，具体色值、亮/暗模式及可访问性测试未冻结。
3. **Lifestyle题目保留“带图三选项”的互动形式**，不是纯文字清单；仍服从既有五场景/每题三选项题库、答案与进度合同。选中态不遮挡文字。
4. A1视觉修订方向、A2关键状态概念方案、A3 Lifestyle 异常与恢复概念，Owner分别表示同意/没问题。**这种接受仅指继续设计时的概念方向**，不等于逐像素视觉验收、工程实现授权或产品合同冻结。

## 2. 仍保持有效的既有Owner规则（EXISTING_BASELINE）
- 首页“精选/好友”两个频道；访客仅可只读官方开放正文，不能看到用户站内公开作品、好友动态或做任何互动；有效已登录用户能按当前授权阅读其有权内容。
- 注册成功后一次可跳过Lifestyle欢迎页；正式真实匹配前Lifestyle必须完成。
- **正式真实匹配必须通过真实实人核验**；供应商尚未接入，不得假显示核验成功或可报名。星盘及MBTI不作真实Match硬门槛；已有资料合法复用。
- Match、Connection、Messaging Consent、Conversation、Relationship均相互独立；持续自动参与需独立授权，不能自动接受候选或许可私聊。
- App四个底部入口：首页／匹配／消息／我的；不新增第五个顶层入口。

## 3. A1–A3顾问设计（ADVISOR_PROPOSAL，非产品交付）
- A1：首次欢迎→单题探索；内容优先首页；匹配准备单一下一操作。不要兴趣九宫格代替五个正式场景。
- A2：登录/访客两种Home状态，匹配准备“Lifestyle未完成／内部完成但实人核验不可用”两种状态；场景题目单题带图三选项。用户真实数据决定状态，图中的完成记录只是假设示例。
- A3：保存中不自动前进；保存失败显示未确认、保留本机选择并重试；返回改选需服务端确认；再次进入需核对账号并恢复已确认进度；切账号不泄漏旧账号缓存。
- 构成主义承担分区和视觉流向；二次元场景是低密度小插画；淡青绿／浅蓝底、深青按钮、避免大块刺眼白底与高饱和红色。
- **A3四屏概念**：保存中、保存失败、返回改选、重新进入恢复。图像说明见 [A1–A3设计归档](../product/ELITESYNC_V2_UI_CONCEPT_A1_A3_20261118.md)。
