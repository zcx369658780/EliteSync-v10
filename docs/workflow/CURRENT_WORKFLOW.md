## 验证按风险选择

| 改动 | 默认验证 |
|---|---|
| 文档、摘要、整理规则 | 差异、链接、内容和状态检查 |
| 小型业务逻辑或 UI 修复 | 受影响检查/定向测试；必要的一次最短功能验证 |
| 跨 APP/API/持久化功能 | 最短真实开发链，验证核心行为与必要持久化；可用虚构数据 |
| 鉴权、加密、数据迁移等高风险逻辑 | 有针对性的正反例、必要回归和对应风险审查 |

检查通过后继续交付；只有新修改、失败或具体风险才扩大/重复检查。不以数百项主机保护测试阻挡普通功能开发；不删除现有鉴权、私信保护或数据隔离。未运行写 NOT_RUN，未核实写 UNKNOWN，最终功能标准与当前未完成项仍保留。

正常导航、空页切换、等待和有限重读是范围内实现细节。仅错身份/设备、真实数据风险、不可逆操作、明确额度/时间边界、Owner 停止等实质条件暂停受影响部分，不逐动作询问。
