- 局部测试误清库与后续MariaDB并发回归证明：必须核有效连接器`APP_DB_CONNECTION`（优先于`DB_CONNECTION`）、独立库/卷、备份与事务真实时序；高风险竞态记录精确reader/writer连接与user PRIMARY等待，不把全局等待计数、exit0异常或缓存命中当证据。
- `CURRENT_STATE.md`、`DOC_INDEX_CURRENT.md`与`docs/memory/navigation.md`多年/月度快照出现重复“当前”，2026-10-19 ChatGPT项目源的01/03/04/索引已明显过期。为避免新顾问错误重派/重规划，引入**一个简短可更新的实时入口**及显式项目源里程碑同步，不清洗历史。
