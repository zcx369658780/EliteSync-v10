| 方式 | 如何取得事实 | 可成立的结论 | 局限与门 |

## 首选方式 B 的固定候选协议

**前置输入。** 由后继任务单固定：一个权威目标实例及库的受控标识、部署版本/哈希、Web 服务池及 worker 清单、CLI 执行上下文、数据库侧观察者身份、单一时间窗、内部请求来源与认证方法、读/写连接路径是否分离、代理或连接池拓扑、回退负责人。原始主机/库/账号/连接串只允许授权的两个受控进程在内存中读取和比较，不写普通证据。没有权威目标或无法把请求定向/归因到具体 worker，前置门失败。

**观测上下文。** 诊断必须经真实 Web SAPI 的已部署 Laravel 请求进入所指定 worker，而非 `php artisan`、独立 CLI bootstrap、静态健康页或测试进程。它在固定默认连接上最多一次只读会话身份查询，取连接会话号、当前库及获批的只读实例标识；如果应用实际存在独立写连接，必须作为另一条路径另行预算并观测，不能用默认读连接代替。数据库侧观察者在同一时间窗从权威实例的获准只读会话视图匹配**活动会话号及请求关联标记**，确认该会话所在实例/库；随后对 CLI 以同一规则独立核对。单纯两端会话号相等没有意义，连接池复用、重连、代理改写和克隆同名均须由观察者显式排除或归为 UNKNOWN。若 DB 平台缺少可安全观察的会话视图或明确关联标记，就停止，不以哈希补证。

**预算模板，运行前仍须由 Work 锁定实际拓扑。** 每个已识别 worker 最多一次内部请求；候选上限 4 个 worker、总共 4 次 Web 请求。超过 4 个或无法逐一命中则停止并重开设计，不能抽样宣称全池。每次请求最多一个应用侧 DB 连接、一次只读会话身份查询；数据库侧每次最多一次只读会话归属观察；CLI 最多一次连接和一次同类查询。若读/写分离，另立预算，不临场加查询。每次连接 5 秒、单请求 10 秒、总时窗 60 秒；任何超时即止。传给普通回执的单行 UTF-8 JSON 最多 512 bytes，stdout/stderr 原始内容不得保存；若进程/工具不能阻止原始日志、代理日志或错误回显中的标识泄漏，运行前门失败。这些数字是**候选上限**，不是本任务可消耗的额度。

**输出白名单。** 仅 `protocol_version`（固定整数）、`window_id`（非秘密随机标记的受限格式）、`worker_slot`（1–4 的匿名序号）、`path_kind`（`default_read`/经另行授权的 `write`）、`web_session_bound`、`cli_session_bound`、`same_authoritative_target`（各 `PASS`/`FAIL`/`UNKNOWN`）、`error_class`（固定安全枚举）、`query_count`、`request_count`。不输出原始连接号、实例/主机/库/用户/对象名、网络端点、SQL、连接串、异常文本、请求头或响应正文。原始标识与标记仅在预先授权的内存比较器中短暂存在，完成或失败立即丢弃；不得写文件、日志或聊天。严格拒绝重复/额外/缺失键、错误类型、超长输出、非单行或非法 UTF-8。

**判定与停点。** `PASS` 需在固定窗口内对每个指定 worker 的每条已授权连接路径完成请求归因、活动会话与权威实例/库匹配，并对 CLI 独立完成同等核对；只记录本次时窗。明确不匹配为 `FAIL`，无法观察、worker 遗漏、连接重连/代理路由未闭合、读写路径缺失、同名克隆无法排除、连接/查询超额、输出越界或诊断暴露面不明均为 `UNKNOWN` 或安全失败，立即停止后续调用。任何非 PASS 不启动备份。计划外 UAC、权限提升、部署、真实查询或生产请求均须停下，另获任务授权；若可能触发 UAC，Owner 必须先在**当前 Work 会话**输入“我在”，该语句仍不代替具体授权。现场失败不自动重试，不在运行时改目标、参数或拓扑。
