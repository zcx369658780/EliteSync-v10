## 单一目的和对象上限

目的仅是为**将来另立任务**设计一条对同一受保护实例的只读诊断：识别运行中 sshd 的有效配置来源、该配置引用的有限 host-key **公钥**来源及算法、监听状态，供后续独立信任锚比较和网络准入核验。一次实例内观察不能单独证明服务器身份、外部可连通性或备份安全。

| 对象（拟议硬上限） | 权威来源与最小读取范围 | 最多可证明 / 不能证明 |
| --- | --- | --- |
| 一个目标实例 | Owner 指定对象的受保护标识须由**独立、预固定**的可信控制面记录与命令助手所选对象精确比较；仅在受保护临运行记录处理原值，普通证据只留 `MATCH/NO/UNKNOWN`。 | 可证明本次调用选中了预固定对象；AUTH-128 同页观察、历史地址及镜像标签不能提供独立预固定标识。当前来源未固定，故 `UNKNOWN`。 |
| 一个运行中 sshd 服务身份及其有效配置来源 | 目标机上先固定实际服务管理方式、进程/可执行文件身份和只读有效配置观察方法；限定一个服务实例、主配置及至多 8 个**由有效配置明确引用**的包含项。超过上限即停，不遍历目录。 | 可识别这一服务本次配置解释的来源；静态文件、发行版默认值及服务名称不能代替运行中状态，也不能证明网络准入。 |
| 至多 4 个有效 `HostKey` 对应的**公钥**对象 | 只从已确定的有效配置和经独立核定的公钥映射取候选；逐个预固定算法、公钥文件身份和只读访问方式。`HostKey` 指令在 OpenSSH 文档中指向**私钥**，不得直接打开它或机械附加后缀猜公钥。 | 只能给 `PUBLIC_SOURCE_CANDIDATE` 与算法类别；该公钥是否为对端实际提供的 key、是否匹配独立信任锚，均待另门。缺映射或数量超界即停。 |

任何对象均不授权扫描任意目录、遍历密钥、读取 host 私钥、客户端密钥、`.env`、真实 DB、业务数据或备份。对象上限是**候选设计的拒绝阈值**，不是本机现状陈述。若多服务、包含关系、动态配置或 socket activation 使“运行中有效配置”无法精确关联，保持 `UNKNOWN`。

## 一次命令助手候选的硬门与当前缺口

拟议现场形态上限：在阿里云轻量应用服务器官方控制面，对预固定的**唯一实例**最多发起**一次**命令助手调用；脚本必须无秘密、只读，不能写文件、修改服务或网络、提权、调用 SSH、DB 或备份。命令助手文档允许选择执行用户及 10～86400 秒超时，默认 Linux 用户为 root；因此必须显式指定经审查的最小权限用户，不能接受默认 root。文档还说明命令详情可查看执行结果和脚本内容；不能视作无痕临时通道。

**完整命令文本/参数：`NOT_FIXED`，不存在可执行候选。** 不能安全填写解释器绝对路径和字节身份、依赖二进制及版本/哈希、执行用户与所需权限、服务进程/有效配置读取方式、公钥映射、监听观察方法、工作目录和环境。AUTH-128 镜像标签不证明实例内 OS 或这些对象。OpenSSH 的 `HostKey` 指令指向私钥，故凭发行版惯例拼出公钥路径会违反本任务的私钥禁止边界。现时也没有已核定的控制面留存时限和可见者；即使凑出只读命令也不能提交现场审查。

若后继从独立可信来源补齐上述每项，须由**新任务**把一份不可临场修改的完整脚本、参数、解释器与所有被调用程序的绝对身份/哈希、显式用户、最小权限、固定对象标识和运行前状态预检写入受保护临运行材料，再独立审查。该材料必须证明不读私钥或其他禁止对象，并验证命令助手对脚本和结果的访问控制与留存时限。任何一项不能固定即 `NO-GO`；现场不得查找路径、替换算法/程序/用户或重试。不得将本段当作运行命令或未来调用预算。

## 输出和留存合同（供后继审查，不是已实现投影器）

拟议正常 stdout **仅**以下固定 ASCII 键和值，每键恰好一次、固定顺序、无额外字节：`INSTANCE_MATCH=YES|NO|UNKNOWN`、`PUBLIC_SOURCE_CANDIDATE=YES|NO|UNKNOWN`、`HOST_KEY_ALGORITHM_CLASS=ED25519|ECDSA|RSA|OTHER|MULTIPLE|UNKNOWN`、`CONFIG_LISTENER_MATCH=YES|NO|UNKNOWN`、`ERROR_CLASS=NONE|PRECHECK|PERMISSION|SOURCE|LIMIT|MISMATCH|TIMEOUT|OUTPUT|OTHER`。算法类别只适用于经核定的公钥候选；多种或无法唯一分类时不得伪报单一算法。另只允许 `PUBLIC_SOURCE_COUNT=0..4`、`CONFIG_SOURCE_COUNT=0..8`、`LISTENER_COUNT=0..4`。不得输出公钥、指纹、路径、端口数字、地址、实例/账号标识或配置原文；`YES` 也不等于信任验证。拟议 stderr 固定为空，非零退出时 stdout 只能是同样脱敏的固定错误类别；无法保证异常、解释器报错及命令助手自身诊断也满足白名单，就在运行前 `NO-GO`。控制面可能生成的错误内容不能被未经核定的程序自行“清洗”为安全。

供未来独立审查的**设计上限**：命令助手任务超时 10 秒，端到端观察上限 30 秒；stdout 和 stderr 各最多 256 字节，合计最多 512 字节；超过任一上限或白名单、缺字段、重复字段、非预期退出码均 `ERROR_CLASS=OUTPUT/OTHER` 并失败即停。拟议退出码仅 `0=完整有限观察`、`1=预检/来源/权限不满足`、`2=数量或输出超界`；超时和控制面失败单列 `UNKNOWN`，不伪造进程退出码。这些限额**尚未由脚本和平台行为实现或验证**，因此本次不授予调用。脚本与控制面结果均可能留存；官方资料证明“可查看”而未核定实例/账号下的可见者、审计副本、删除权或留存时限，当前 `RETENTION_ACCESS=UNKNOWN`、`NO-GO`。未来需来自阿里云正式策略/账号授权记录的可信边界及 Owner 对留存的具体同意；不能用“稍后删除”替代。

本地普通证据只投影审查过的类别、计数、退出类别、时间窗和预算，不保存原始页面、命令输出、脚本详情或截图；受保护临运行记录也须单独限定接收者和期限。当前无运行回执、无本地投影文件。

## 结论分门和后继停点

1. **找到候选来源**：只有受限命令经新任务获准并按白名单完成，才可称本次找到了公钥候选和有效配置/监听类别；目前全部 `UNKNOWN`。
2. **独立指纹比较**：候选来源的公钥指纹必须与独立于 SSH 首次握手及该实例内自报值的受保护信任锚，经另获审查的受控通道比较。现无锚、算法与通道，`HOST_KEY_VERIFIED=UNKNOWN`；本机历史 `known_hosts`、`ssh-keyscan`、旧 SSH 成功均不能充当锚。
3. **有效配置与监听匹配**：即使内部匹配，也只是目标机内部一致性；当前未观察，`CONFIG_LISTENER_MATCH=UNKNOWN`。
4. **网络准入**：同一目标和端口的轻量云侧规则、主机防火墙及外部准入需各自授权的独立只读来源。单次实例内诊断不能给 `PORT_VERIFIED=YES`；当前 `PORT_VERIFIED=UNKNOWN`。

在任何现场动作前，Work 须另发精确任务，独立 LEVEL 3 审查脚本、依赖身份、目标技术绑定、留存/访问、最小权限及错误输出，Owner 对一次现场调用给出具体授权和预算。若登录、密码、真人识别或 Windows UAC 可能出现，触发前停；Owner 必须在**当前 Work 会话**确认“我在”并亲自处理，旧在场确认及“我在”本身均不代替任务放行。启动后的非零、异常、身份变化、输出超界或超时均记预算耗尽，失败即停，不重试、不改走 VNC/SSH/云 API。AUTH-121/122/123 各 1/1、AUTH-128 页面 1/1 及其他耗尽预算不重置。本轮现场调用预算 **0**，没有 SSH、DB、dump、传输、恢复或首次备份许可。
