## 唯一拟粘贴文本（POSIX Linux Shell）

以下代码块内为完整文本，不含占位符、凭据、实例标识、地址、端口或文件路径。它仅调用 `id -u`；`command -v` 是 Shell 内建查询，**不调用** `sshd`、`systemctl` 或 `service`。重定向到空设备只丢弃输出，不持久写文件。

```sh
exec 2>/dev/null || exit 3
u=$(id -u 2>/dev/null) || { printf 'AUTH140=ID_ERROR\n'; exit 2; }
case "$u" in
  0) k=ROOT ;;
  ''|*[!0-9]*|0*) printf 'AUTH140=ID_ERROR\n'; exit 2 ;;
  *) k=NONROOT ;;
esac
if command -v sshd >/dev/null 2>&1; then s=YES; else s=NO; fi
if command -v systemctl >/dev/null 2>&1; then t=YES; else t=NO; fi
if command -v service >/dev/null 2>&1; then v=YES; else v=NO; fi
printf 'AUTH140=OK UID=%s SSHD=%s SYSTEMCTL=%s SERVICE=%s\n' "$k" "$s" "$t" "$v"
```

成功时 stdout 恰好一行，模式为 `AUTH140=OK UID=ROOT|NONROOT SSHD=YES|NO SYSTEMCTL=YES|NO SERVICE=YES|NO`，退出 0；三个工具位只表示当前 Shell 的 `PATH`/命令解析环境可定位该**名称**，不证明文件字节身份、实际可执行性、服务正在运行、配置、算法、host-key、监听端口或防火墙。`id -u` 非零或返回非规范数字时 stdout 恰好 `AUTH140=ID_ERROR`，退出 2。最初 stderr 重定向失败时预期退出 3，但 Shell 或平台可能先产生非白名单错误；一律作为异常停，不转发原文。任意非零、额外输出、超时、缺失/重复字段、无法取得可靠进程退出码或平台错误都不得推断能力为 NO，记失败并停。
