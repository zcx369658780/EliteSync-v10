## 2. 模拟器能力边界

Android模拟器可通过开发工具注入模拟短信事件，但这不代表短信经真实运营商网络发送，也不能证明实体SIM当前控制原号码。

禁止：
- 将模拟器注入短信作为号码控制权证明。
- 将模拟器生成的发送者号码当作真实来电/短信号码。
- 使用ADB或模拟器控制台伪造运营商短信送达。
- 将Owner口头陈述、旧数据库记录或历史ADMIN_PHONES命中描述成独立挑战验证。

## 4. 可选核验路径

### 路径A：已有获批的独立号码验证渠道

如果Owner有已批准且可用的运营商账户门户、可信短信/语音服务或其他独立验证渠道，可以核验原号码控制权。不得自动注册服务或产生未经批准费用。

### 路径B：Owner本人签署自我声明

Owner可以明确决定：不要求独立短信挑战，将其本人关于当前仍控制原号码的明确声明作为本次恢复的持有人证明。

若Owner选择此路径：
- 证据类型必须标记为 `owner-self-attestation`，不得标记为SMS/OTP/第三方核验。
- `verified_by=owner-self-attestation`。
- 回执记录Owner声明时间、有效期、候选代号、旧管理员名单匹配证据引用和Owner责任声明。
- Owner在受控环境对最终Manifest进行Ed25519签名，明确承担该持有人证明的责任。
- 仍须满足现有LegacyAdminApproval的字段、目标绑定、时间窗和签名验证要求。
- 该路径的保证级别低于独立号码挑战，报告必须明确说明。

选择路径B属于对原核验强度的明确Owner决策，不能由Codex或顾问自行推定。

### 路径C：等待第二个真实端点

Owner日后取得第二台实体手机、第二条独立号码或获批核验服务后，再执行真实短信/语音挑战。
